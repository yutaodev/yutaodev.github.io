二、第一节 经络的发现

经络是经脉和络脉的总称，是人体内运行气血、联络脏腑、沟通内外、贯穿上下的通路。经络的发现主要通过以下途径：

一、针灸等刺激后感应传导现象的总结

针刺穴位时患者会产生酸、麻、胀、重等“针感”，常沿一定路线向远部传导。《灵枢·邪气脏腑病形》载：“中气穴，则针游于巷。”温灸时热感也由施灸部位向远处扩散。经过长期观察，古代医家逐步认识到人体各部有复杂而又有规律的联系通路。

二、腧穴主治功效的总结

发现腧穴不仅能治疗局部病证，还能治疗远隔部位的病证，而且这些主治范围基本相同的穴位往往有规律地排列在一条线路上，为经络的存在提供了佐证。

三、气功“行气”感的反复出现

《灵枢·官能》载：“缓节柔筋而心和调者，可使导引、行气。”在导引行气过程中常出现“气”在体内有规律地流行的感觉。《行气玉佩铭》是战国初期的文物，记载了行气过程的描述。长沙马王堆汉墓出土的《导引图》与记载十一脉的文字连在一起，说明导引行气与经络的密切关系。

四、体表病理现象的总结

当体内某一脏腑发生疾病时，在体表相应部位可出现压痛、结节、皮疹、皮肤色泽改变等异常反应。《灵枢·背腧》载：“欲得而验之，按其处，应在中而痛解，乃其腧也。”《素问·脏气法时论》记载心病时胸中痛、胁支满、肩背间痛、两臂内痛等，说明体表病理现象与经络有密切联系。

五、解剖生理知识的启发

《灵枢·经水》记载古人通过解剖观察，对人体内脏的位置、形态及某些生理功能有了直观认识，发现人体分布着许多与四肢相联系的管状和条索状结构，对认识经络有一定的启发。

三、第二节 经络系统的组成

经络系统由经脉、络脉和连属于体表的十二经筋、十二皮部组成。经脉包括十二经脉、奇经八脉、十二经别；络脉包括十五络脉和难以计数的浮络、孙络等。

一、十二经脉

十二经脉是经络系统的主体，是手三阴经、手三阳经、足三阳经、足三阴经的总称，又称“正经”。

（一）十二经脉的名称

根据手足、阴阳、脏腑命名。手六经和足六经；属五脏和心包的为阴经，属六腑的为阳经；阴阳分三阴（太阴、厥阴、少阴）三阳（阳明、少阳、太阳）。十二经脉名称：手太阴肺经、手阳明大肠经、足阳明胃经、足太阴脾经、手少阴心经、手太阳小肠经、足太阳膀胱经、足少阴肾经、手厥阴心包经、手少阳三焦经、足少阳胆经、足厥阴肝经。

（二）十二经脉在体表的分布规律

  • 阳经：分布于四肢外侧和头面、躯干。上肢外侧为手三阳经，下肢外侧为足三阳经。分布规律：阳明在前、少阳在中（侧）、太阳在后。
  • 阴经：分布于四肢内侧和胸腹。上肢内侧为手三阴经，下肢内侧为足三阴经。手三阴分布规律：太阴在前、厥阴在中、少阴在后。足三阴在内踝上8寸以下：厥阴在前、太阴在中、少阴在后；8寸以上：太阴在前、厥阴在中、少阴在后。

（三）十二经脉表里属络关系

阴经属脏络腑，阳经属腑络脏。表里配对：足太阳与少阴、少阳与厥阴、阳明与太阴；手太阳与少阴、少阳与心主、阳明与太阴。互为表里的经脉在生理上有密切联系，病变时相互影响，治疗时可相互为用。

（四）十二经脉循行走向与交接规律

  • 走向：手三阴经从胸走手，手三阳经从手走头，足三阳经从头走足，足三阴经从足走腹（胸）。（《灵枢·逆顺肥瘦》）
  • 交接：①相表里的阴经与阳经在四肢末端交接；②同名的阳经与阳经在头面部交接；③相互衔接的阴经与阴经在胸中交接。

（五）十二经脉气血流注规律

气血流注始于手太阴肺经→手阳明大肠经→足阳明胃经→足太阴脾经→手少阴心经→手太阳小肠经→足太阳膀胱经→足少阴肾经→手厥阴心包经→手少阳三焦经→足少阳胆经→足厥阴肝经→上注肺→重新循环，如环无端。

二、奇经八脉

奇经八脉指督脉、任脉、冲脉、带脉、阴维脉、阳维脉、阴跷脉、阳跷脉八条。因与十二经脉不同而别道奇行，既不直属脏腑，除任、督外又无专属穴位和表里配合关系。

  • 十四经：任脉和督脉各有其所属腧穴，与十二经相提并论合称“十四经”，其他六条奇经没有专门腧穴。
  • 临床意义：八脉交会穴、灵龟八法和飞腾八法都是这一理论的具体运用。

三、十二经别

十二经别是十二经脉别行深入体腔的支脉。

特点：循行分布具有离、入、出、合的特点。多从四肢肘膝关节附近正经别出（离）→经过躯干深入体腔与相关脏腑联系（入）→再浅出体表上行头项部（出）→在头项部阳经经别合于本经经脉，阴经经别合于相表里的阳经经脉（合）。由此十二经别按阴阳表里关系会合成六组，称为“六合”。

作用：

  1. 加强表里两经的联系。
  2. 加强经脉与脏腑的联系，为表里配穴法提供理论依据。
  3. 加强十二经脉与头部的联系，为头针、面针、耳针等奠定理论基础。
  4. 弥补十二经脉分布的不足，扩大经穴的主治范围。如足阳明经别上通于心，为“和胃气以安心神”的治法提供理论依据。

四、十五络脉

十二经脉和任脉、督脉各自别出一络，加上脾之大络，总计15条。分别以所别出处的腧穴命名。也有“十六络”之说，包括胃之大络（虚里）。

分布：十二经脉别络在四肢肘膝关节以下本经络穴分出后，均走向其相表里的经脉；任脉络从鸠尾分出散布于腹部；督脉络从长强分出散布于头部，走向背部两侧足太阳经；脾之大络出于大包穴，散布于胸胁部。

作用：

  1. 四肢部十二经别络沟通表里两经，加强表里联系。
  2. 统属全身浮络、血络、孙络，渗灌血液、营养周身、贯通营卫。
  3. 根据络脉病候和沟通表里两经的特点，选用络穴治疗络脉虚实病证和表里两经病变。

五、十二经筋

十二经筋是十二经脉之气结、聚、散、络于筋肉关节的体系，是附属于十二经脉的筋肉系统。

分布特点：循行走向均从四肢末端走向头身，行于体表，不入内脏。有结、聚、散、络的特点，结聚部位多在关节及肌肉丰厚处。足三阳经筋起于足趾，循股外上行结于颅（面部）；足三阴经筋起于足趾，循股内上行结于阴器（腹部）；手三阳经筋起于手指，循臑外上行结于角（头部）；手三阴经筋起于手指，循臑内上行结于贲（胸部）。刚筋（阳筋）分布于项背和四肢外侧；柔筋（阴筋）分布于胸腹和四肢内侧。

作用：约束骨骼，利于关节屈伸活动，保持人体正常运动功能（“宗筋主束骨而利机关也”）。治疗：多局部取穴，用燔针劫刺，“以痛为输”。

六、十二皮部

十二皮部是十二经脉功能活动反映于体表的部位，也是络脉之气在皮肤所散布的部位。

分布：以十二经脉体表的分布范围为依据。作用：居于人体最外层，是机体的卫外屏障，有保卫机体、抗御外邪和反映病证的作用。临床应用：各种灸法、挑刺、拔罐、穴位敷贴及皮肤针法等都与皮部关系密切。

四、第三节 经络的标本、根结和气街、四海

一、标本

“标”指上部，与头面胸背相应；“本”指下部，与四肢下端相应。本在四肢肘膝以下的一定部位，标在头、胸、背部。

二、根结

“根”指根本、开始（四肢末端井穴），“结”指结聚、归结（头、胸、腹部）。《标幽赋》：“更穷四根三结，依标本而刺无不痊。”“四根三结”指十二经脉以四肢为“根”，以头、胸、腹三部为“结”。

“根”与“本”、“结”与“标”：位置相近或相同，意义相似。“根”“本”部位在下，为经气始生始发之地；“结”“标”部位在上，为经气所结、所聚之处。“标本”范围较“根结”更广，强调经脉分布上下部位的相应关系；“根结”强调经气两极间的联系。

三、气街

气街是经气聚集运行的共同通路。《灵枢·卫气》：“胸气有街，腹气有街，头气有街，胫气有街。”

部位：《灵枢·卫气》：“气在头者，止之于脑。气在胸者，止之膺与背俞。气在腹者，止之背俞，与冲脉于脐左右之动脉者。气在胫者，止之于气街，与承山踝上以下。”

特点：横向为主、上下分部、紧邻脏腑、前后相连。为临床配穴处方提供理论依据。

四、四海

四海即髓海、血海、气海、水谷之海的总称。《灵枢·海论》：“人有髓海，有血海，有气海，有水谷之海，凡此四者，以应四海也。”

四海 部位 功能
髓海 头部 元神之府，神气的本源
气海 胸部 宗气所聚之处，贯心脉而行呼吸
水谷之海 上腹部（胃） 营气、卫气的化源之地，气血生化之源
血海 下腹部（冲脉） 十二经之海，起于胞宫，与原气关系密切

四海病变分有余、不足两大类，对临床辨证施治具有指导意义。

五、第四节 经络的作用和经络学说的临床应用

一、经络的作用

《灵枢·经脉》：“经脉者，所以能决死生，处百病，调虚实，不可不通。”

  1. 联系脏腑，沟通内外：十二经脉“内属于腑脏，外络于肢节”，奇经八脉沟通于十二经之间，经筋、皮部联结了肢体筋肉皮肤，使人体各脏腑组织器官有机地联系起来。

  2. 运行气血，营养全身：“经脉者，所以行血气而营阴阳，濡筋骨，利关节者也。”气血通过经络传注输布全身，维持机体正常功能。

  3. 抗御病邪，反映病候：孙络“以溢奇邪，以通营卫”，最先接触到病邪。经络是外邪内传的渠道（皮毛→孙脉→络脉→经脉→内连五脏）。脏腑病变可通过经络反映到体表组织器官。

  4. 传导感应，调和阴阳：针刺得气和行气现象都是经络传导感应的功能表现。“刺之要，气至而有效。”针灸刺激体表穴位，经络传导到有关部位和脏腑，调节人体脏腑气血，使阴阳平复。

二、经络学说的临床应用

（一）诊断方面

  1. 经络辨证：根据疾病所出现的症状，结合经脉循行部位及所联系的脏腑进行辨证。如头痛：前额（阳明）、侧头（少阳）、后头（太阳）、巅顶（厥阴）。

  2. 经络望诊：观察全身经络穴位的色泽、形态变化（皮肤皱缩、隆陷、松弛、颜色变异、光泽明晦、色素沉着、斑疹等）。《灵枢·经脉》：“凡诊络脉，脉色青则寒且痛，赤则有热。”

  3. 经络腧穴按诊：在经络腧穴部位按压、触摸寻找异常变化（压痛、硬结、条索状物、肿胀、凹陷等）。按诊部位多为背俞穴、募穴、原穴、郄穴、合穴或阿是穴。切脉也是其重要组成部分。

  4. 经络腧穴电测定：利用经络穴位测定仪检测腧穴部位的电参量，判断各经气血之盛衰。

（二）治疗方面

  1. 指导针灸临床选穴：以循经取穴为主——某一经络或脏腑有病，选用该经或相应经脉的腧穴治疗。如上病下取、下病上取、中病旁取、左右交叉取、前后对取等。《四总穴歌》：“肚腹三里留，腰背委中求，头项寻列缺，面口合谷收。”

  2. 指导刺灸方法的选用：皮肤针、皮内针（皮部理论）；刺络出血治疗目赤肿痛、咽喉肿痛、急性腰扭伤等（“菀陈则除之”）；经筋病多局部取穴，用燔针劫刺。

  3. 指导药物归经：药物按其主治性能归入某经或某几经。如柴胡治寒热往来，能愈少阳之病；桂枝治畏寒发热，能愈太阳之病；葛根治肢体大热，能愈阳明之病。
