二、第一节 常用针灸器具

针灸器具可分为传统针灸器具和现代针灸仪器两大类。

一、传统针灸器具

（一）针刺用具

《灵枢·九针十二原》记载了九种不同形状和用途的金属针具：镵针、圆针、鍉针、锋针、铍针、圆利针、毫针、长针、大针，称为“九针”。

针具 来源/特点 主要用途
毫针 现代最常用，不锈钢制，规格多样 全身各部腧穴，内、外、妇、儿各科病证
芒针 由“长针”发展而来，针身≥5寸 深刺或透刺，善治深邪远痹
三棱针 由“锋针”改制，针身粗、针尖锋利 刺络放血
火针 由“大针”衍化，单头/三头之分 寒痹、虚寒性胃肠病证、外科皮肤病证（烧针加热后点刺）
铍针 如刀 切割皮肤肌肉，排脓治痈肿
皮肤针 后人发明 叩刺皮肤
皮内针 后人发明 埋藏皮内
针刀 后人发明 松解粘连

（二）灸材与灸具

  • 艾绒：以艾叶制成，湖北蕲州产者为佳（“蕲艾”）。特点：易于燃烧、热力温和持久、穿透力强，温通散寒作用明显。
  • 艾炷和艾条（艾卷）：临床应用最广泛。
  • 其他灸材：灯心草（灯火灸）、白芥子/细辛/大蒜/斑蝥（天灸）。
  • 灸具：温灸筒、温灸盒、熏灸器等——灸火集中、温热持久、较少烟尘、舒适安全。

（三）拔罐用具

传统罐具有陶罐、竹罐、金属罐、玻璃罐。目前临床最广泛的是竹罐和玻璃罐。

二、现代针灸仪器

  1. 电针仪：输出脉冲电流，发挥针刺和电刺激双重作用。多为集成电路仪器，交直流两用，安全省电、体积小、性能稳定。
  2. 灸疗仪：
    • 电热艾灸仪（电加热艾绒）
    • 电热喷灸仪（加热特制艾药饼产生热气流）
    • 电热温灸仪（稀土电发热材料，可控温度）
    • 光灸仪（红外线/远红外线/激光）
  3. 拔罐仪：
    • 抽气罐（负压可控，使用安全）
    • 多功能拔罐仪（负压+磁+热综合作用）
  4. 其他：特定波谱治疗仪（TDP）、电磁疗机、激光针灸仪、微波针灸仪、导平仪等。

三、第二节 常用针灸体位

一、针灸体位的意义

适宜体位便于正确定位取穴、方便施术、持久留针，防止晕针、滞针、弯针、折针等意外。《备急千金要方·灸例》：“凡点灸法，皆须平直……若坐点则坐灸之，卧点则卧灸之，立点则立灸之。”

二、针灸体位的选择

体位 姿势 适宜取穴部位
仰卧位 仰卧，四肢自然伸直 头、面、胸、腹部腧穴和四肢部分腧穴
侧卧位 侧卧，四肢自然屈曲 身体侧面少阳经腧穴和上下肢部分腧穴
俯卧位 俯卧，上肢环抱于颌下，下肢平伸 头、项、脊背、腰骶部腧穴和下肢后侧及上肢部分腧穴
仰靠坐位 背靠坐椅，头仰靠椅背 前头、颜面和颈前等部位腧穴
俯伏坐位 伏坐，头自然俯伏于椅背 后头和项、背部腧穴
侧伏坐位 侧伏，头侧伏于治疗床或椅背 侧头部、面颊及耳前后部位腧穴

注意：

  • 同一患者同次治疗尽可能选用一种体位。
  • 对初诊、精神紧张或年老、体弱、病重患者，宜采取卧位。

四、第三节 常规针灸治疗量

针灸治疗量是提高疗效、保证安全的关键因素。

一、针刺治疗量的形成要素

  1. 取穴多少：取穴多→刺激大；取穴少→刺激小。慢性/复杂/全身性疾病取穴较多；急性/单纯/局部病证取穴较少。宜“少而精”（《针灸大成》：“故不得其要，虽取穴之多，亦无以济人”）。

  2. 针具粗细：粗针→刺激量大，泻邪作用强；细针→刺激量小，补虚适宜。

  3. 针刺深浅：深刺→刺激强度大，适用于筋骨深部病证；浅刺→刺激强度小，适用于皮肤浅表病证（《素问·刺要论》：“病有浮沉，刺有浅深，各至其理”）。

  4. 手法轻重：

    • 轻手法：捻转幅度小、频率慢、提插幅度小、运针时间短→刺激量小→适用于体质弱/慢性病
    • 重手法：捻转幅度大、频率快、提插幅度大、运针时间长→刺激量大→适用于体质强/急性病
    • 补泻手法与强弱刺激既有联系又有区别，应在掌握强弱刺激基础上施以补泻手法。

  5. 留针时间长短：留针时间长→刺激量大；留针时间短→刺激量小（《灵枢·邪气脏腑病形》：“刺急者，深内而久留之；刺缓者，浅内而疾发针”）。

二、艾灸治疗量的形成要素

  1. 艾炷大小：小炷（麦粒大）、中炷（苍耳子大）、大炷（莲子大）。艾炷越大→艾火越强→作用量越大（《扁鹊心书》：“凡灸大人，艾炷须如莲子……灸四肢及小儿，艾炷如苍耳子大；灸头面，艾炷如麦粒子大”）。

  2. 壮数多少：一壮=燃尽一个艾炷。壮数越多→作用量越大（《备急千金要方》：“凡言壮数者，若丁壮遇病……可倍多于方数；其人老少羸弱者，可复减半”）。

  3. 灸火强弱：与艾炷大小、艾条距离、艾绒燃烧程度相关。一般艾条燃端距施灸部位2～3cm。强灸火→实证/急性病/体质壮者；弱灸火→虚证/慢性病/体质弱者。

  4. 施灸时间长短：一般每穴10～15分钟。初灸每日1次，3次后2～3天1次。急性病可每日2～3次（《医宗金鉴》：“凡灸诸病，必火足气到，始能求愈”）。

三、常规针灸治疗量的确定

基本原则：①得气（取得良好疗效的前提）；②适度（过则伤正，不及则无功）。

综合因素：除形成要素外，还需考虑患者禀赋、体质、年龄、性别、病性、病位、病程等。

治疗常规：

  • 治疗次数：常规每日1次；可一日2次或两日1次。
  • 留针时间：一般15～30分钟，行针守气（每5～10分钟行针一次）。
  • 疗程：一般1～2周为一疗程。

五、第四节 针灸施术的注意事项

一、施术前的消毒

提倡使用一次性无菌针具。

  1. 针具器械消毒：

    • 一次性针具：检查包装密封完好，保质期内使用。
    • 多针包装若一次未用完，剩余针具需用75%乙醇消毒后方可使用。
    • 用后针具放入专用容器，统一收回处理。

  2. 医者双手消毒：先用肥皂水洗手，干后再用75%乙醇棉球擦拭。避免手指直接接触针身，必要时用无菌干棉球隔物。

  3. 针刺部位消毒：用75%乙醇棉球或1.5%碘伏，从中心点向外绕圈擦拭。

  4. 治疗室消毒：卫生洁净，定期消毒净化，空气流通。床垫、枕巾等按时换洗。

二、刺灸法的宜忌

（一）施术部位的宜忌

  1. 避开重要脏器：《素问·刺禁论》：“脏有要害，不可不察。”胸、胁、腰、背、缺盆等部位不宜直刺深刺，以免伤及脏腑。肝脾大者、肺气肿患者尤应注意。小腹针刺前应先排尿。

  2. 避开重要器官组织：眼区不宜大幅度提插捻转；项部深层为延髓，脊柱深层为脊髓，均不可深刺（《素问·刺禁论》：“刺头中脑户，入脑立死”）。

  3. 避开特殊部位：大血管旁（人迎、委中、箕门、气冲、曲泽、经渠、冲阳等）应避开血管；乳中、脐中一般不刺；小儿囟门未闭禁针；皮肤感染、溃疡、创伤、瘢痕或肿瘤部位不宜针灸。

（二）患者状态的宜忌

  1. 体质状态：初病/体质强壮者→治疗量宜大；久病/体质虚弱/老人/儿童→治疗量宜小，宜卧位。

  2. 机能状态：

    • 大醉、大怒、饥饿、疲劳、精神过度紧张者→不宜立即针灸。
    • 首次接受针灸者→做好解释，克服恐惧。
    • 妇女行经（非调经者）→慎用针刺。
    • 孕妇（尤其习惯性流产史）→慎用；下腹、腰骶部及三阴交、合谷、昆仑、至阴等通经活血穴→禁针。

（三）病情性质的宜忌

  1. 病情程度：

    • 气血严重亏虚（大出血、大吐、大泄、大汗）→不宜针刺。
    • 形体极度消瘦（癌症、慢性肝炎晚期）→不宜针刺。
    • 传染性强、凝血机制障碍→一般不宜针刺。

  2. 疾病性质：

    • 表证→浅刺（表寒久留，表热疾出）
    • 里证→深刺（里寒补法灸法，里热泻法）
    • 虚证→补法（虚寒少针多灸，虚热多针慎灸）
    • 实证→泻法（表实浅刺，里实深刺）
    • 寒证→深刺久留
    • 热证→浅刺疾出，或刺络出血
