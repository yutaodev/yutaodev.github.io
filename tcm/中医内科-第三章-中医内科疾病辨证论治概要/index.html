第三章 中医内科疾病辨证论治概要

第一节 风寒暑湿燥火辨治概要

外感风、寒、暑、湿、燥、火称为外感六淫。《素问·至真要大论》谓：“夫百病之生也，皆生于风寒暑湿燥火，以之化之变也。”在疾病过程中，由于人体气、血、津、液气化异常和脏腑功能失调，产生类似风、寒、湿、燥、火致病特点的邪气，称为“内生五邪”。外感六淫与内生五邪在致病特点和辨治方法上异中有同，故合为一节概述。

一、风

风有外风、内风之分。外风为六淫之首，属春令主气，流动于四时之中。其性轻扬，为病多犯上焦，肺卫首当其冲。《素问·风论》云：“风者，百病之长也。”内风主要是指肝经病变的一类证候表现，《素问·至真要大论》云：“诸风掉眩，皆属于肝。”肝为风木之脏，主藏血，主筋，肝病则风从内生，称为“肝风内动”。外风可人里，引动内风，内风也可及表，病及经络。

风性主动，善行数变。如病情突然发作，或来去无常，或变化多端，病变部位游走或动摇不定。外风首犯肺卫，易于侵犯人体的上部和卫表，常以肺系、卫表、肌肤、肢体、经络见症为主，实证居多，以风寒、风热、风湿兼为常见。内风多易上冒、旁走，有虚有实。虚者为阴虚血亏，筋脉失养，或水不涵木；实者为肝阳化风、热极生风；但虚实每多兼夹，因阳亢与阴虚可以互为因果。

外风宜疏风解表，内风宜平肝息。针对夹寒、夹热、夹湿、夹痰等不同，应采取不同治法。在外风引动内风时，祛风与息两法并用。

二、寒

寒有内寒与外寒之别。寒为阴邪，冬季主气。外寒是外界寒气侵犯人体，伤肌表为伤寒，直中脏腑称中寒；内寒是机体阳气不足，温煦力弱，寒从内生。《素问·至真要大论》：“诸寒收引，皆属于肾。”外寒易犯肺胃，内寒多责命门，累及心脾。阳虚易外感寒，久寒必伤阳。

寒邪阴冷凝滞、收引，易伤阳气，多见拘紧疼痛。外寒治宜温散，内寒治宜温补。

三、暑

暑为夏季专属阳邪，由火热化生，《素问·热论》：“后夏至日者为病暑。”暑性升散，易耗气伤津，暑气通心，易高热神昏；盛夏多夹湿。治暑必顾津气，夹湿佐芳香化湿。

四、湿

分外湿、内湿。长夏主外湿，久居湿地、涉水淋雨易发病；内湿源于脾，嗜生冷肥甘损伤脾胃。《素问·至真要大论》：“诸湿肿满，皆属于脾。”湿邪重浊黏滞，易遏阳气，可夹风、寒、热。外湿宜微汗、渗利，内湿重在健脾，分宣上、畅中、渗下三法。

五、燥

燥分外燥、内燥。秋令主外燥，初秋温燥，深秋凉燥；内燥由热盛、汗吐失血、久病耗伤津液而成，累及肺胃肝肾，以干燥诸症为核心。治燥以生津润燥为主，外燥轻宣，内燥滋阴。

六、火

分外火、内火。外感温热暑为外火，五气皆可化火；内伤五志、劳欲、积热内生虚实火。火为热之极，易耗伤津血，传卫气营血。实火宜泻火，虚火宜滋阴降火。

第二节 脏腑病证辨治概要

脏腑病证，是指脏腑在发生病理变化时反映于临床的症状和体征。由于各个脏腑的生理功能和病理变化有所不同，故表现的病证也多种多样。根据各个脏腑不同的生理病理辨析病证，这就是脏腑辨证。临床的辨证方法虽然很多，且各有特点，但要辨明病证的部位、性质，并指导治疗，每多需要落实到脏腑上。因此，脏腑辨证是辨证论治的核心。 人体是以脏腑为中心的有密切联系的整体。五脏之间有生克乘侮的关系，五脏与其相应的六腑、四肢、皮肤、筋、脉、肉、五官七窍等组织器官构成了人体脏腑系统。从脏腑经络系统、气、血、津、液、升降出入以及四时与五脏相应等方面，把握人体是以五脏为中心的整体观内涵非常重要。因此，在进行脏腑辨证时一定要从整体观念出发，不仅要考虑一脏一腑的病理变化，还必须注意脏腑间的联系和影响，才既能准确认识某一脏腑病的本证，又能把握病变全局。 五脏六腑通过各自所属的经络，将四肢百骸、五官九窍、皮肉筋脉等联结成一个有机的统一整体，所以脏腑的病证与十二经脉又密切相关，因此，认识脏腑的病证应联系经脉的循行部位，综合分析。 气血津液由脏腑化生、输布，而脏腑又赖之以进行正常的生理活动，脏腑发生病变则可影响气血津液的化生和输布，而气血津液的病变也可影响脏腑的功能活动，所以气血津液的病变不能离开脏腑的病变而孤立存在。 脏腑病证，既涉及气血津液，又与经络密切相关，虽然错综复杂，但归纳其证候性质，仍不出八纲辨证的范围，因此，脏腑辨证，还必须以八纲辨证为基础，进行分析研究，才能全面地认识病证的本质。

一、肺

肺居胸腔，左右各一，其位最高，又称五脏之“华盖”，与大肠互为表里。 肺主气，司呼吸，主宣发肃降，通调水道，朝百脉而主治节。肺在体合皮，其华在毛，开窍于鼻，在液为涕，在志为忧，通于秋气。因肺叶娇嫩，不耐寒热，又为呼吸之通道，故外感病邪，常先犯肺，又称“娇脏”。肺朝百脉而通他脏，故他脏有病，也常累及于肺。肺之病证，有邪实和正虚两端。邪实者，多为外邪所致，或寒闭，或热，或痰阻，若病久不愈，正气日虚，或肺气亏虚，或肺阴耗伤。

（一）辨证原则

肺系病证的辨证应分虚实。虚证有阴虚、气虚、气阴两虚；实证有风、寒、热、痰、饮、瘀等。

（二）辨主症

  1. 辨咳嗽 由于邪阻于肺，肺失宣肃，肺气上逆而作。据其病程的久暂，可分为暴咳与久咳两类。暴咳，病程短，外感所致，每多夹有表证，分为风寒、风热、风燥等。久咳，病程长，内伤所致，多伴他脏形症，常因感受外邪发作或加重，分为痰湿、气火、阴虚、气虚等。
  2. 辨喘 以呼吸喘促，甚则张口抬肩为特征。主要病机为肺气升降出入失常。辨证可分为虚、实两大类。实喘，由外邪、痰浊壅肺，肺气失于宣降所致。多呈急性发作，呼吸深长有力，气粗声高，脉数有力。虚喘，由于久病体虚，精气亏损，肺不主气，肾不纳气所致。病程迁延不已，病情时轻时重，呼吸短浅难续，气怯声低，脉来微弱。
  3. 辨痰 此痰指有形之痰液。由于肺气失于敷布，津液停聚而成。可从痰的色、质、量、气味等辨其病理性质。外感时邪所致之痰，病程短，多伴表证，有风寒、风热、痰热、风燥等不同。内伤之痰，多属久病，反复缠绵，有肝火、脾湿、气虚、阴虚之别。
  4. 辨咳血 多为火盛伤络，络损血溢，或阴虚火旺，灼伤肺络所致。常分虚实两类。属实热证者，咳痰带血，血色深红，或咳血量多。属于虚者，常为阴虚所致，症见干咳痰少，痰中带血，时作时止。
  5. 辨失音 语声嘶哑，或暗而不能出声者为失音。分虚实两类。实证，属外感，时邪阻遏肺气，会厌开合不利所致，多为“暴喑”；虚证，属内伤，阴精内耗，咽喉、声道失于滋润，多为“久喑”。

（三）治则治法

肺实者，宜疏邪祛痰利气。偏于寒者宜温宣，偏于热者宜清肃。肺虚者，应辨其阴虚、气虚而培补之。阴虚者，滋阴养肺；气虚者，补益肺气；气阴两虚者，治当兼顾。

（五）临证备要

  1. 肺主气，居上焦，用药宜轻，味宜辛。清·吴鞠通《温病条辨》云：“治上焦如羽，非轻不举。”故选方用药宜轻扬而忌重浊，多用苦甘辛平肃降肺气，或用苦辛温开肺气，或用微辛而酸以敛肺气，一般不用血分药。倘肺气虚而不能摄纳，则又当佐以和营养血之品，有利于肺气之肃降。如痰浊夹有瘀血阻滞，苔腻舌紫，则当使用化痰祛瘀之法。
  2. 由于肺合皮毛而开窍于鼻，因此皮肤干燥，或痛或痒，或麻木不仁，或风疹瘙痒，甚至皮硬等症，辨治均可参用宣肺润降之品。经常鼻塞流涕或鼻孔干燥、出血等，也可参用清肺、养肺类药物。
  3. 肺与大肠相表里，临床治疗肺经实热，可以通过泻下通腑，使肺热下行。若因肺气失宣不能布津，大肠失润，燥屎干结难行者，当于润肠通腑药中，增入开提肺气之品，使肠润便通。
  4. 他脏病及肺者，或肺病及他脏者，应重视其他脏腑的治疗。如肺实火证，出现气火咳逆时，可用泻肝而达到清肺的目的；肺气虚弱之久咳、痰多、纳差者，可用培土生金法健脾以补肺。若外感风邪，肺气不宣，不能通调水道，肺病及肾，开阖不利，成风水证者，治当宣肺利水，犹如提壶揭盖，使小便畅而浮肿消。

二、心

心居胸中，心包围护其外，心主血脉，为生命活动的中心；又主神明，为五脏六腑之大主。心在体合脉，其华在面，开窍于舌，在液为汗，在志为喜，通于夏气。心不受邪，外邪入侵，多为心包所受。心之本脏病多起于内伤，如禀赋不足、脏气虚弱、病后失调以及思虑过度伤及心脾，均可导致心阴虚或心阳虚。若思虑太过，气机郁结，津液凝聚，生化火，痰火上扰，或气滞脉中，瘀血阻络，或饮邪阻遏心阳，可出现心之热证和实证。临床常见血脉运行障碍和情志思维活动异常表现。

（一）辨证原则

心病的辨证应分虚实。虚证有阳虚（含气虚）和阴虚（含血虚）两类，亦可阴阳两虚并见。实证为痰、火、水饮、瘀血等病邪阻滞，也可相兼为病。

（二）辨主症

  1. 辨惊悸、怔忡 两者均指心中悸动不安，是心脏气机失和所致。辨证分虚实：虚证由气血阴阳亏虚，心神失养；实证多为痰火、水饮、瘀血扰动心神。
  2. 辨真心痛 《灵枢·厥病》：“真心痛，手足清至节，心痛甚，旦发夕死。”多由气血瘀滞，心脉痹阻而成，本虚标实，临床需区分寒凝、痰浊、气滞、气虚血瘀不同证型。
  3. 辨昏迷、虚脱 昏迷分热闭、痰闭、寒闭，属邪实重症；虚脱为阴阳衰竭，以面色苍白、大汗、脉微欲绝为主，多见亡阳危候。
  4. 辨水肿 心阳不振，气化失司，水液停聚，以下肢水肿为主，伴心悸喘促。

  1. 气虚日久可发展为阳虚，血虚久耗多伴阴虚，临床多见气血、阴阳两虚复合证；

三、脾

脾居中焦，与胃互为表里，为后天之本。脾主运化、升清、统摄血液；在体合肉，其华在唇，开窍于口，在液为涎，在志为思，通长夏。脾喜燥恶湿，运化失常则湿浊内生，故脾病以湿邪为核心标邪，分虚、实两类。

（一）辨证要点

虚证：脾气虚、脾阳虚、中气下陷、脾不统血； 实证：寒湿困脾、湿热蕴脾； 主症辨识：泄泻、脘腹痞满、水肿、出血、肢体痿软。

（二）治则

虚证健脾益气、温中升提；实证温化寒湿、清热利湿；脾宜升健，胃宜通降，脾胃同病升降并调。

  2. 肝阳、肝风根源多为肾阴不足，平肝必兼顾滋肾；
  3. 肝胆湿热黄疸、胆石证需通腑泄热；
  4. 妇女肝病多冲任失调，疏肝佐调经养血。

五、肾

肾居下焦，左右各一，与膀胱互为表里；为先天之本，藏精，主水，主纳气，主骨生髓，开窍于耳、二阴，其华在发，在志为恐，通于冬。肾藏元阴元阳，肾病纯实证极少，多本虚标实。

（一）辨证要点

本虚：肾气虚、肾阳虚、肾阴虚、肾精不足； 标实：水湿、浊毒、砂石、瘀血； 主症：腰膝酸痛、水肿、小便异常、生殖机能减退、咳喘气短（肾不纳气）。

（二）治则

阳虚温肾，阴虚滋肾，肾精填精；水湿利水，浊毒通腑泄浊，砂石通淋排石。

  1. 阴阳互根，久阳虚佐少量滋阴药，久阴虚轻补阳，避免偏弊；
  2. 纯滋阴易滋腻碍胃，温阳药多燥热，配伍平和健脾药；
  3. 水肿不可单一峻逐水，治标后温肾固本；
  4. 小便不通伴频繁呕吐为关格，浊毒内蕴危证，需扶正泄浊急救。

第三节 气血津液辨证概要

气血津液是脏腑气化生成的基础精微物质，气为血帅，血为气母，津血同源，三者失常依附脏腑病变存在。

一、气病辨证

  1. 气虚：脏腑机能衰减，气短乏力、自汗、舌淡脉弱，治补气，四君子汤；
  2. 气滞（气郁）：气机阻滞，胸胁脘腹胀痛走窜，治行气，柴胡疏肝散；
  3. 气陷：气虚升举无力，内脏下垂、久泻脱肛，治益气升提，补中益气汤；
  4. 气逆：肺胃气上冲，咳喘、呕吐呃逆；肝气上冲头痛，治降气，苏子降气汤、旋覆代赭汤；
  5. 气脱：元气暴脱，大汗肢冷神昏，急救大补元气，独参汤；
  6. 气闭：气机猝然闭塞，突发昏厥，顺气开窍，五磨饮子。

二、血病辨证

  1. 血虚：周身失濡，面白唇淡、头晕心悸，养血，四物汤、归脾汤；
  2. 瘀血：刺痛固定，瘀斑舌紫，活血化瘀，血府逐瘀汤；
  3. 血热：身热出血，舌红绛，清热凉血，犀角地黄汤；
  4. 血寒：冷痛、经血瘀黑块，温经散寒，温经汤。

三、津液病辨证

  1. 津液亏虚（内燥）：口鼻皮肤干燥、便干，生津润燥，沙参麦冬汤；
  2. 水湿内停：浮肿身重，健脾利水，五苓散；
  3. 痰饮：痰稠为痰，清稀为饮，温化为主，苓桂术甘汤。

临证要点

气血津液病极少单独发病，必结合脏腑虚实辨证，标本同步调治。

第四节 经络辨证概要

经络是人体运行气血、沟通脏腑与四肢百骸的通路，经脉为主干，络脉为分支；经筋主束骨利关节，皮部主卫外御邪。气血依靠经络输布濡养全身，脏腑病变、外感邪气均可造成经络气血阻滞或失养，引发肢体疼痛、麻木、痿软、抽搐等症。经络辨证多用于痹证、痿证、颤证、痉证、腰痛等肢体经络疾病，常配合八纲、脏腑、气血津液辨证综合使用。 经络病变总分两大类：

  1. 实证（不通）：风寒湿热、痰瘀血阻滞经络，气血运行不畅，以疼痛、肿胀、僵硬、活动不利为主；
  2. 虚证（不荣）：气血、肝肾精亏，经络筋脉失于濡养，以肢体痿弱、麻木、细微震颤、肌肉萎缩为主。

三、经络辨证核心理论阐述

  1. 经络生理联系 十二经脉内连五脏六腑，外络皮肉筋骨；奇经八脉调节十二经气血，经筋约束关节、皮部护卫肌表。气血依靠经络输送，经络依赖气血濡养，二者互为根本。凡外感风寒湿热、内伤痰瘀、久病气血亏虚，均会破坏经络气血运行，产生各类肢体病证。
  2. 虚实辨别要点 实证：病程较短，疼痛剧烈、肿胀僵硬、按压痛甚，遇寒湿、情绪波动加重，多由外邪、瘀血、痰浊阻滞经络而成； 虚证：病程长久，隐痛、麻木、肢体软弱无力、肌肉萎缩，劳累后明显加重，无明显肿胀灼热，根源在脾胃、肝肾精血不足，经络得不到濡养。
  3. 三类经络病分治逻辑 （1）痹阻类（痹证）：以“通”为核心，祛风、散寒、清热、化痰、活血通络，久痹必加虫类药（全蝎、地龙、乌梢蛇）搜剔深络； （2）失养类（痿证）：以“补”为本，健脾益气、滋养肝肾，佐少量通络药，不可单用祛风燥湿药耗伤阴血； （3）风动类（颤、痉）：实热宜凉肝息风，阴虚血虚宜滋阴养血柔筋，禁用峻烈发散药。

四、临床运用细则

  1. 定位辨证：疼痛、麻木沿哪条经脉分布，即可判定病位，搭配对应引经药直达病所；
  2. 久病入络：病程超过三个月，单纯草木药难达深层脉络，必须配伍藤类、虫类通络药材； 3 内外合治：内服汤药配合针灸、推拿、中药熏洗，疏通经络效果更佳；
  3. 治病求本：经络病症根源均关联脏腑，腰痛治肾、四肢痿软健脾、震颤调肝，不可只治肢体局部。

五、本章收尾小结

六淫、内生五邪是外感内伤基础病机；脏腑辨证为内科辨证核心；气血津液是脏腑功能化生的精微物质；经络辨证专门针对四肢、躯体、五官经脉病变。 临床辨证必须综合八纲、脏腑、气血津液、经络四类体系，先分寒热虚实，再定病位，区分标本缓急，分步施治。
