二、总论

脾系病证是由于饮食因素、感受外邪、情志所伤、体弱久病等，影响脾的运化、胃的腐熟功能而引起的病证，病位主要在脾胃。脾胃位于中焦，脾主运化水谷精微，以升为健，喜燥恶湿；胃主受纳腐熟水谷，以降为和，喜润恶燥。脾系病证的发生主要由于脾胃的纳运功能失常所致，恢复脾胃纳运功能为基本治疗原则。

脾系病证临床常分虚实：虚在气、血、阴、阳；实在湿、食、寒、热。小儿脾常不足，虚实相兼常见。治疗时不宜轻用攻伐，也不可骤补。补虚时必须补中寓运，消积时又需消中兼补，燥湿时必须燥中寓濡，滋阴时又当滋中潜化。

三、第一节 鹅口疮

鹅口疮以口腔黏膜、舌上散在或满布白屑为主要特征，因其白屑状如鹅口故称。西医学亦称为鹅口疮，由白色念珠菌感染所致。常见于新生儿及体质虚弱、营养不良、久病久泻或长期使用广谱抗生素者。

【病因病机】

病变部位在心、脾、肾，病机为火热之邪循经上炎，熏灼口舌。

  1. 心脾积热：孕母喜食辛辣炙烤→胎热遗儿；产道秽毒侵入；喂养不当，脾胃蕴热；口腔不洁，秽毒乘虚而入。口为脾之窍，舌为心之苗，心脾积热循经上行→熏灼口舌。
  2. 虚火上浮：胎禀不足，素体阴虚；久病体虚；热病伤阴→肾阴亏虚→水不制火→虚火上浮→熏蒸口腔。

【临床诊断】

诊断要点：多见于新生儿或久病体虚、久泻儿，或有长期使用广谱抗生素或糖皮质激素史。口腔黏膜出现乳白色斑膜，形似奶块，常见于颊黏膜、舌、齿龈、上腭。擦去斑膜后可见红色创面。婴幼儿拒食、吮乳啼哭。

鉴别诊断：与白喉（见第四章表4-3）、口疮（见表5-1）、残留奶块（轻拭可去）鉴别。

【辨证论治】

分证论治

1. 心脾积热

  • 证候：口腔、舌面满布白屑，周围嫩红较甚，面赤唇红，烦躁不宁，吮乳啼哭，大便秘结，小便短赤，舌红苔白厚腻，脉滑数。
  • 辨证要点：白屑多，周围红，面红唇赤。
  • 治法：清心泻脾。
  • 主方：清热泻脾散（《医宗金鉴》）加减。

2. 虚火上浮

  • 证候：口腔舌面白屑散在，周围红不重，形体怯弱，面白颧红，手足心热，口干不渴，或低热盗汗，舌红少苔，脉细数无力。
  • 辨证要点：白屑散在，周围红不重，舌红少苔。
  • 治法：滋阴降火。
  • 主方：知柏地黄丸（《医宗金鉴》）加减。

【其他疗法】

  • 中成药：导赤丸（心脾积热）；知柏地黄丸（虚火上浮）。
  • 外治：冰硼散、珠黄散、青黛散涂敷（心脾积热）；西瓜霜喷剂、开喉剑喷雾剂；吴茱萸粉陈醋调敷涌泉穴（虚火上浮）。
  • 西医：2%～5%碳酸氢钠溶液清洗口腔；制霉菌素混悬液涂拭。

【预防调护】

加强孕期卫生保健；注意口腔清洁，奶瓶奶嘴消毒；避免过烫过硬食物；提倡母乳喂养；避免长期使用广谱抗生素或激素；观察病情变化。

四、第二节 口疮

口疮以口腔黏膜、舌体及齿龈等处出现大小不等淡黄色或灰白色溃疡，局部灼热疼痛，或伴发热、流涎为特征。西医学疱疹性口炎、溃疡性口炎、复发性口腔溃疡等可参考本病辨证施治。以2～4岁婴幼儿多见。

【病因病机】

病位主要在心、脾、肾，病机为心脾肾三经素蕴积热，或阴虚火旺，复感邪毒熏蒸口舌。

  1. 风热乘脾：外感风热→犯于肺卫→内乘脾胃→循经上攻→熏灼口舌。
  2. 心火上炎：外感传里化火，或饮食不当→心火循经上炎→熏灼口舌。
  3. 脾胃积热：嗜食肥甘厚味→蕴而生热→积于心脾→循经上行→腐蚀肌膜。
  4. 虚火上浮：禀赋不足，素体阴虚；热病久泻→阴液亏耗→水不制火→虚火上炎。

【临床诊断】

诊断要点：齿龈、舌体、两颊、上腭等黏膜处出现黄白色溃疡，大小不等，甚则满口糜腐，疼痛流涎，进食困难，可伴发热咽痛。

鉴别诊断（见表5-1）：与鹅口疮（白屑可拭去）、手足口病（斑丘疹疱疹）鉴别。

【辨证论治】

分证论治

1. 风热乘脾

  • 证候：唇舌口颊齿龈溃烂，周围焮红，灼热疼痛，流涎拒食，伴发热咽喉红肿疼痛，舌红苔薄黄，脉浮数。
  • 辨证要点：外感引起，疱疹溃烂，灼热疼痛，流涎拒食。
  • 治法：疏风散火，清热解毒。
  • 主方：银翘散（《温病条辨》）加减。

2. 心火上炎

  • 证候：疱疹溃疡以舌面、舌边尖为多，红肿灼热，疼痛明显，面赤唇红，心烦尿赤，舌边尖红苔薄黄，脉细数。
  • 辨证要点：舌面、舌边尖溃烂，色赤疼痛，心烦尿赤。
  • 治法：清心凉血，泻火解毒。
  • 主方：泻心导赤散（《医宗金鉴》）加减。

3. 脾胃积热

  • 证候：唇口颊上腭齿龈溃疡糜烂，色白或黄，甚则满口糜烂，边缘鲜红，疼痛拒食，口臭流涎，面赤口渴，大便秘结，小便短赤，舌红苔黄，脉数。
  • 辨证要点：口腔溃疡较多，红肿疼痛，口臭流涎，大便秘结。
  • 治法：清热解毒，通腑泻火。
  • 主方：凉膈散（《太平惠民和剂局方》）加减。

4. 虚火上浮

  • 证候：口腔溃烂点少，表面黄白色，周围色不红或微红，疼痛不甚，反复发作迁延不愈，神疲颧红，手足心热，口干不渴，舌红少苔或花剥，脉细数。
  • 辨证要点：反复发作，口舌溃疡稀疏色淡，神疲颧红，舌红少苔。
  • 治法：滋阴降火，引火归原。
  • 主方：知柏地黄丸（《医宗金鉴》）加减。

【其他疗法】

外治：冰硼散、青黛散、西瓜霜、珠黄散（实证）；锡类散（虚证）；吴茱萸粉陈醋调敷涌泉穴（虚证）。推拿分证治疗。西医：抗病毒（阿昔洛韦），局部用药。

五、第三节 呕吐

呕吐是因胃失和降，气逆于上，胃中乳食上逆经口而出的一种病证。发病无年龄及季节限制，婴幼儿多见，好发于夏秋季节。

【病因病机】

病位主要在胃，与肝脾相关，病机为胃失和降，气逆于上。

  1. 外邪犯胃：感受六淫→客于胃肠→胃失和降→胃气上逆。
  2. 乳食积滞：乳食不知自节→乳食停留，蓄积中焦→脾胃失健→升降失调。
  3. 胃中积热：过食辛热厚味或感受暑热→热积胃中→胃热气逆。
  4. 脾胃虚寒：先天禀赋不足，或过食生冷，或寒凉克伐→中阳不运→胃失和降。
  5. 肝气犯胃：情志怫郁→肝气不舒→横逆犯胃→气机上逆。

【临床诊断】

诊断要点：乳食等从胃中上涌，经口而出；有嗳腐食臭，恶心纳呆，胃脘胀闷。重证可见阴伤液竭之象（皮肤干瘪、囟门目眶下陷、啼哭无泪、尿少或无尿、神昏抽搐）。

鉴别诊断：与溢乳鉴别（见表5-2）——溢乳为生理性，乳汁自口角溢出，无其他症状；呕吐为病理性，呕吐物为乳食伴不消化物，有嗳腐纳呆等症状。

【辨证论治】

分证论治

1. 寒邪犯胃

  • 证候：起病急，突发呕吐，吐物清冷，胃脘不适或疼痛，伴发热恶寒，鼻塞流涕，舌淡红苔白，脉浮紧。
  • 辨证要点：突发呕吐，吐物清冷，伴发热恶寒，鼻塞流涕。
  • 治法：疏风散寒，化湿和中。
  • 主方：藿香正气散（《太平惠民和剂局方》）加减。

2. 乳食积滞

  • 证候：呕吐酸臭乳块或不消化食物，不思乳食，口气臭秽，脘腹胀满，吐后觉舒，大便秘结或泻下酸臭，舌红苔厚腻，脉滑数有力。
  • 辨证要点：有伤乳伤食史，吐物为乳块或不消化物，吐后得舒，苔厚腻。
  • 治法：消乳化食，和胃降逆。
  • 主方：伤乳用消乳丸（《证治准绳》）；伤食用保和丸（《丹溪心法》）。

3. 胃热气逆

  • 证候：食入即吐，呕吐频繁，呕秽声洪，吐物酸臭，口渴多饮，面赤唇红，烦躁少寐，舌红苔黄，脉滑数。
  • 辨证要点：呕吐频繁，食入即吐，呕吐物热臭气秽。
  • 治法：清热泻火，和胃降逆。
  • 主方：黄连温胆汤（《六因条辨》）加减。

4. 脾胃虚寒

  • 证候：食后良久方吐，或朝食暮吐，暮食朝吐，吐物多为清稀痰水或不消化乳食残渣，面色苍白，精神疲倦，四肢欠温，腹痛便溏，舌淡苔白，脉迟缓无力。
  • 辨证要点：食后良久方吐，吐物不化，清稀而不臭，舌淡苔白。
  • 治法：温中散寒，和胃降逆。
  • 主方：丁萸理中汤（《医宗金鉴》）加减。

5. 肝气犯胃

  • 证候：呕吐酸苦，或嗳气频频，每因情志刺激加重，胸胁胀痛，精神郁闷，易怒易哭，舌边红苔薄腻，脉弦。
  • 辨证要点：嗳气吐酸，遇情志刺激加重，舌边红苔薄腻，脉弦。
  • 治法：疏肝理气，和胃降逆。
  • 主方：解肝煎（《景岳全书》）加减。

【其他疗法】

外治：鲜地龙捣烂敷双足心（胃热气逆）；大蒜吴茱萸敷双足心（脾胃虚寒）；鲜生姜片贴太渊穴防服药呕吐。推拿分证治疗。针灸：体针（中脘、足三里、内关），耳针（胃、肝、交感、皮质下），艾灸（天枢、关元、气海，用于脾胃虚寒）。

六、第四节 腹痛

腹痛指胃脘以下、脐之两旁及耻骨以上部位的疼痛。6岁以内高发。儿科腹痛大体上分为功能性与器质性两种，功能性腹痛占50%～70%。本节主要论述功能性腹痛（包括肠系膜淋巴结炎引起的腹痛）。

【病因病机】

病位主要在脾、胃、大肠，与肝有关，病机为脾胃、肠腑气滞。

  1. 腹部中寒：衣被单薄，或过食生冷→寒邪凝滞→气机不畅→不通则痛。
  2. 乳食积滞：喂养不当，暴饮暴食→脾胃运化失常→乳食积于中焦→气机壅塞。
  3. 胃肠积热：乳食停滞化热，恣食肥甘辛热，或外邪入里化热→热结阳明→腑气不通。
  4. 脾胃虚寒：禀赋不足素体阳虚，过用寒凉攻伐，病后体虚→中阳不振→血脉凝滞。
  5. 气滞血瘀：情志不畅，跌打损伤，久病不愈→气滞血瘀→经络不通。

【临床诊断】

诊断要点：疼痛部位在胃脘以下、脐周、小腹两侧或下腹正中。腹痛时作时止，反复发作可自行缓解。疼痛性质有隐痛、钝痛、胀痛、刺痛。腹软，一般无肌紧张及反跳痛。

鉴别诊断：外科急腹痛（起病急骤，由轻到重，持续剧痛，体征局限）与内科腹痛（起病较缓，时作时止，可自行缓解）鉴别（见表5-3）；功能性腹痛（无明显诱因，反复发作，无明显体征）与器质性腹痛（有原发病，疼痛与疾病密切联系）鉴别（见表5-4）。

【辨证论治】

分证论治

1. 腹部中寒

  • 证候：腹部疼痛，甚者拘急蜷伏，得温则舒，遇寒痛甚，痛处喜暖，面色苍白，肢冷不温，或兼吐泻，舌淡苔白滑，脉沉弦紧。
  • 辨证要点：腹痛较剧，痛处喜暖，得温则舒，遇寒痛甚，舌淡苔白滑。
  • 治法：温中散寒，理气止痛。
  • 主方：养脏汤（《医宗金鉴》）加减。

2. 乳食积滞

  • 证候：脘腹胀满，按之痛甚，嗳腐吞酸，不思乳食，矢气频作或腹痛欲泻，泻后痛减，大便秽臭，夜卧不安，舌红苔厚腻，脉沉滑。
  • 辨证要点：脘腹疼痛拒按，不思乳食，嗳腐吞酸，大便秽臭，舌苔厚腻。
  • 治法：消食导滞，行气止痛。
  • 主方：香砂平胃散（《医宗金鉴》）加减。

3. 胃肠积热

  • 证候：腹痛胀满，疼痛拒按，大便秘结，烦躁口渴，手足心热，口唇舌红，舌苔黄燥，脉滑数。
  • 辨证要点：腹痛胀满，疼痛拒按，大便秘结，舌苔黄燥。
  • 治法：通腑泄热，行气止痛。
  • 主方：大承气汤（《伤寒论》）加减。

4. 脾胃虚寒

  • 证候：腹痛绵绵，时作时止，痛处喜按，得温则舒，面色㿠白，精神倦怠，手足清冷，纳食减少，大便稀溏，舌淡苔白，脉沉细。
  • 辨证要点：腹痛绵绵，喜按喜温，大便稀溏，舌淡苔白。
  • 治法：温中理脾，缓急止痛。
  • 主方：小建中汤（《伤寒论》）合理中丸（《伤寒论》）加减。

5. 气滞血瘀

  • 证候：腹痛经久不愈，痛有定处，痛如针刺，或腹部块拒按，肚腹硬胀，青筋显露，舌紫黯或有瘀点，脉涩。
  • 辨证要点：痛有定处，痛如锥刺，拒按或腹部癥块，舌紫黯有瘀点，脉涩。
  • 治法：活血化瘀，行气止痛。
  • 主方：少腹逐瘀汤（《医林改错》）加减。

【其他疗法】

中成药：四磨汤口服液、藿香正气液、保和丸、理中丸、元胡止痛片。

外治：丁香豆蔻肉桂白胡椒研末填敷脐中（脾胃虚寒）。

推拿分证治疗。针灸：体针（足三里、合谷、中脘、天枢）；耳穴压豆（胃、脾、肝、胆）。

七、第五节 泄泻

泄泻以大便次数增多，粪质稀薄或如水样为特征。发病年龄以婴幼儿为主，6个月～2岁发病率最高。夏秋季节高发。本病轻证预后良好；重证可出现气阴两伤，甚至阴竭阳脱。

【病因病机】

病位主要在脾胃，病机为脾困湿盛，升降失司，水反为湿，谷反为滞，清浊不分，合污下降。

  1. 感受外邪：外邪（尤以暑湿）困脾→运化失职→升降失调→水谷不分→泄泻。有“无湿不成泻”之说。
  2. 伤于饮食：乳食不节→损伤脾胃→宿食内停→升降失常→清浊不分。
  3. 脾胃虚弱：素体脾虚或久病迁延→脾胃虚弱→水谷不化→清阳不升。
  4. 脾肾阳虚：脾虚久泻→伤及肾阳→火不暖土→水谷不化→洞泄而下。

变证：暴泻伤阴→气阴两伤；久泻伤阳→阴竭阳脱；久泻脾虚→土虚木贼→慢惊风；脾虚失运→生化乏源→疳证。

【临床诊断】

诊断要点：大便次数明显增多（每日3次以上），性状改变（淡黄色稀糊状/清水样/蛋花汤样/夹奶块/黄绿稀溏/色褐臭秽夹黏液）。重证可见脱水症状（小便短少，精神烦躁或萎靡，皮肤干瘪，囟门凹陷，啼哭无泪等）。

鉴别诊断：与痢疾鉴别（见表5-5）——泄泻便次多质稀薄，无里急后重；痢疾便次少量少，痢下赤白脓血，里急后重，腹痛明显。

【辨证论治】

（一）辨证要点

  • 辨常证、变证：常证轻者便次不多，精神尚好；重者便多次频，发热呕吐，口干尿少。变证见泻下不止，神萎烦躁，目眶囟门凹陷，皮肤干皱。
  • 辨寒热虚实阴阳：便稀如水色淡黄臭味不甚→寒；大便黄褐臭秽→热。暴泻→实证；久泻→虚证或虚实夹杂。变证中气阴两伤→重证；阴竭阳脱→危证。

（二）分证论治

1. 常证

（1）湿热泻

  • 证候：大便水样或蛋花汤样，泻下急迫，量多次频，气味秽臭，或夹少许黏液，肛门红赤，腹痛时作，发热烦哭，口渴尿黄，舌红苔黄腻，脉滑数。
  • 辨证要点：泻下急迫，量多次频，气味秽臭，舌红苔黄腻。
  • 治法：清肠泄热，化湿止泻。
  • 主方：葛根黄芩黄连汤（《伤寒论》）加减。

（2）风寒泻

  • 证候：大便清稀，夹有泡沫，臭味不甚，肠鸣腹痛，或伴恶寒发热，鼻流清涕，咳嗽，舌淡苔薄白，脉浮紧。
  • 辨证要点：大便清稀有泡沫，臭味不甚，肠鸣腹痛。
  • 治法：疏风散寒，化湿和中。
  • 主方：藿香正气散（《太平惠民和剂局方》）加减。

（3）伤食泻

  • 证候：大便稀溏，夹有乳凝块或食物残渣，气味酸臭或如败卵，脘腹胀满，嗳气酸馊，不思乳食，腹痛拒按，泻后痛减，舌苔厚腻，脉滑实。
  • 辨证要点：便稀夹不消化物，气味酸臭，脘腹胀痛，泻后痛减，舌苔厚腻。
  • 治法：消食化滞，运脾和胃。
  • 主方：保和丸（《丹溪心法》）加减。

（4）脾虚泻

  • 证候：大便稀溏，色淡不臭，多于食后作泻，时轻时重，面色萎黄，神疲倦怠，食欲不振，形体消瘦，舌淡苔白，脉缓弱。
  • 辨证要点：反复发作，病程较长，大便稀溏色淡不臭，食后作泻，全身脾虚征象。
  • 治法：健脾益气，助运止泻。
  • 主方：参苓白术散（《太平惠民和剂局方》）加减。

（5）脾肾阳虚泻

  • 证候：久泻不止，食入即泻，大便清稀，澄澈清冷，完谷不化，或见脱肛，形寒肢冷，面色㿠白，精神萎靡，舌淡苔白，脉细弱。
  • 辨证要点：久泻不愈，大便清冷，完谷不化，形寒肢冷，舌淡苔白。
  • 治法：温补脾肾，固涩止泻。
  • 主方：附子理中汤（《三因极一病证方论》）合四神丸（《内科摘要》）加减。
2. 变证

（1）气阴两伤

  • 证候：泻下无度，质稀如水，精神萎弱或心烦不安，目眶及囟门凹陷，皮肤干燥，啼哭无泪，口渴引饮，小便短少甚至无尿，唇红而干，舌红少津，苔少或无苔，脉细数。
  • 辨证要点：泻下无度，质稀如水，目眶囟门凹陷，无泪少尿，舌红少津。
  • 治法：健脾益气，酸甘化阴。
  • 主方：人参乌梅汤（《温病条辨》）加减。

（2）阴竭阳脱

  • 证候：泻下不止，次频量多，精神萎靡，表情淡漠，面色青灰或苍白，哭声微弱，啼哭无泪，尿少或无，四肢厥冷，舌淡无津，脉沉细欲绝。
  • 辨证要点：泻下不止，精神萎靡，面色青灰或苍白，四肢厥冷，尿少或无，脉沉细欲绝。
  • 治法：挽阴回阳，救逆固脱。
  • 主方：生脉散（《医学启源》）合参附龙牡救逆汤（经验方）加减。

【其他疗法】

中成药：保和丸（伤食泻）；葛根芩连微丸、苍苓止泻口服液（湿热泻）；藿香正气口服液（风寒泻）；参苓白术散（脾虚泻）；附子理中丸（脾肾阳虚泻）。

外治：五倍子干姜吴茱萸丁香研末白酒调敷脐（虚寒泻）；丁香肉桂姜汁调敷脐（风寒泻/脾虚泻/脾肾阳虚泻）；鬼针草煎水熏洗双足。

推拿分证治疗。针灸：针法（足三里、中脘、天枢等）；灸法（足三里、中脘、神阙，用于脾虚泻、脾肾阳虚泻）。

西医：调整饮食，预防和纠正脱水（口服补液/静脉补液），合理用药（控制感染、微生态疗法、肠黏膜保护剂、补锌治疗），慎用止泻剂。

八、第六节 便秘

便秘指大便秘结不通，排便次数减少或间隔时间延长，或大便努挣难解。可单独存在，也可继发于其他疾病。功能性便秘占儿童便秘的90%以上。

【病因病机】

病位在大肠，病机为大肠传导失司，与脾、肝、肾三脏相关。

  1. 乳食积滞：饮食喂养不当→损伤脾胃→运化失常→积久化热→耗伤津液→肠道失润。
  2. 邪热伤津：感受温热时邪或过食肥甘炙烤→灼津伤阴→肠道失濡。
  3. 气机郁滞：情志不舒、久坐少动→气机郁滞→大便秘结。
  4. 气血阴津亏虚：素体亏虚或疾病损伤→气虚传导无力，血阴津亏虚肠道失润；肾虚不能蒸化津液→肠道干涸。

【临床诊断】

诊断要点：大便干燥（轻者前部干硬，重者状如羊屎）；排便次数减少（2～3日1次，甚则6～7日1次）；排便艰涩或时间延长；伴腹胀、腹痛、食欲不振、排便哭闹。

鉴别诊断：与先天性巨结肠（顽固性便秘，新生儿胎便排出延迟，钡灌肠示近直肠-乙状结肠狭窄）、机械性肠梗阻（阵发性剧烈腹痛，腹胀呕吐，X线示扩张肠样及液平面）鉴别（见表5-6）。

【辨证论治】

分证论治

1. 食积便秘

  • 证候：大便秘结，脘腹胀满，不思饮食，或恶心呕吐，口臭，手足心热，小便黄少，舌红苔黄厚，脉沉有力。
  • 辨证要点：有伤食史，便秘兼脘腹胀痛、纳呆口臭、手足心热。
  • 治法：消积导滞通便。
  • 主方：枳实导滞丸（《内外伤辨惑论》）加减。

2. 燥热便秘

  • 证候：大便干结，排便困难，甚则便秘不通，面赤身热，腹胀或痛，小便短赤，口干口臭，或口舌生疮，舌红苔黄燥，脉滑实。
  • 辨证要点：大便干结，面赤口臭，身热溲赤，苔黄燥。
  • 治法：清热润肠通便。
  • 主方：麻子仁丸（《伤寒论》）加减。

3. 气滞便秘

  • 证候：大便秘结，欲便不得，胸胁痞满，腹胀疼痛，嗳气频作，舌红苔薄白，脉弦。
  • 辨证要点：欲便不得，胸胁痞满，腹胀嗳气。
  • 治法：理气导滞通便。
  • 主方：六磨汤（《证治准绳》）加减。

4. 气虚便秘

  • 证候：时有便意，大便不干，仍努挣难下，排便时汗出气短，便后神疲乏力，面色少华，舌淡苔薄，脉虚弱。
  • 辨证要点：时有便意，大便不干，努挣难下，神疲乏力。
  • 治法：益气润肠通便。
  • 主方：黄芪汤（《金匮翼》）加减。

5. 血虚便秘

  • 证候：大便干结，艰涩难下，面白无华，唇甲色淡，心悸目眩，舌淡嫩苔薄白，脉细弱。
  • 辨证要点：大便干结，艰涩难下，面白无华，唇甲色淡。
  • 治法：养血润肠通便。
  • 主方：润肠丸（《沈氏尊生方》）加减。

6. 阴虚便秘

  • 证候：大便干结，形体消瘦，口干渴，盗汗，五心烦热，舌红少苔，脉细数。
  • 辨证要点：大便干结，形体消瘦，口干渴，盗汗，舌红少苔。
  • 治法：增液润燥通便。
  • 主方：增液汤（《温病条辨》）合益胃汤（《温病条辨》）加减。

【其他疗法】

外治：大黄研末酒调敷脐（燥热便秘）。推拿：实证（清大肠、退六腑、推下七节骨）；虚证（推下七节骨、补脾经、补肾经）。针灸：体针（大肠俞、天枢、支沟、上巨虚）；耳穴压豆（大肠、便秘点）。

九、第七节 厌食

厌食以较长时期厌恶进食、食量减少为特征。各年龄儿童均可发病，以1～6岁多见，城市儿童发病率较高。长期不愈可影响生长发育，转为疳证。

【病因病机】

病位主要在脾胃，病机为脾胃失健，纳化失和。

  1. 先天因素：先天胎禀不足→脾胃薄弱→生后不欲吮乳。
  2. 后天因素：
    • 喂养不当：未按期添加辅食，过食肥甘，偏食零食，饥饱无度，滥服滋补品→损伤脾胃。
    • 病传药害：屡患他病迁延伤脾；误用攻伐或过用苦寒/温燥→损伤脾胃。
    • 外邪直中：暑湿困脾→脾为湿困→纳化失常。
    • 情志失调：猝受惊恐、打骂、所欲不遂→情志抑郁→肝失条达→乘脾犯胃。

【临床诊断】

诊断要点：长期食欲不振，厌恶进食，食量明显少于同龄正常儿童；面色少华，形体偏瘦，但精神尚好，活动如常；除外其他疾病。

鉴别诊断：与疰夏鉴别（见表5-7）——疰夏多发于春末夏初，江南地区多见，伴精神倦怠、大便溏、舌苔厚腻；与积滞、疳证鉴别（见表5-8）。

【辨证论治】

分证论治

1. 脾失健运

  • 证候：食欲不振，厌恶进食，食而乏味，食量减少，或伴胸脘痞闷，嗳气泛恶，大便不调，形体尚可，精神正常，舌淡红苔薄白或薄腻，脉尚有力。
  • 辨证要点：除厌恶进食外，其他症状不著，精神形体如常。
  • 治法：调和脾胃，运脾开胃。
  • 主方：不换金正气散（《太平惠民和剂局方》）加减。

2. 脾胃气虚

  • 证候：不思进食，食而不化，大便偏稀夹不消化食物，面色少华，形体偏瘦，肢倦乏力，舌淡苔薄白，脉缓无力。
  • 辨证要点：不思乳食，面色少华，肢倦乏力，形体偏瘦。
  • 治法：健脾益气，佐以助运。
  • 主方：异功散（《小儿药证直诀》）加减。

3. 脾胃阴虚

  • 证候：不思进食，食少饮多，皮肤失润，大便偏干，小便短黄，甚或烦躁少寐，手足心热，舌红少津，苔少或花剥，脉细数。
  • 辨证要点：食少饮多，大便偏干，舌红少苔。
  • 治法：滋脾养胃，佐以助运。
  • 主方：养胃增液汤（经验方）加减。

4. 肝脾不和

  • 证候：厌恶进食，嗳气频繁，胸胁痞满，性情急躁，面色少华，神疲肢倦，大便不调，舌淡苔薄白，脉弦细。
  • 辨证要点：食少嗳气，胸胁痞满，神疲肢倦，情志不遂。
  • 治法：疏肝健脾，理气助运。
  • 主方：逍遥散（《太平惠民和剂局方》）加减。

【其他疗法】

香佩疗法（苍术、肉桂、艾叶、佩兰等研末装香囊佩戴）。推拿分证治疗。针灸：体针（脾俞、足三里等）；耳针（脾、胃、肾、神门、皮质下）。

十、第八节 积滞

积滞是内伤乳食，停聚中焦，积而不化，气滞不行所形成的一种胃肠疾病。婴幼儿最为多见。一般预后良好，迁延失治可转为疳证（“积为疳之母，无积不成疳”）。

【病因病机】

病位在脾胃，病机为乳食停聚不消，积而不化，气滞不行。

  1. 乳食内积：乳食不节→脾胃受损→受纳运化失职→宿食停聚→积而不化。
  2. 脾虚夹积：禀赋不足脾胃素虚，病后失调，过用寒凉攻伐→腐熟运化不及→乳食停滞不化。积久不消→损伤脾胃→转为疳证。

【临床诊断】

诊断要点：有伤乳伤食史；不思乳食，食而不化，脘腹胀满，大便溏泄酸臭或臭如败卵，或便秘；可伴烦躁不安、夜间哭闹或呕吐。腹部触诊可有上腹部及脐周压痛。

鉴别诊断：与厌食、疳证鉴别（见表5-8）——积滞以不思乳食、脘腹胀满、嗳吐酸腐、大便酸臭为特征；厌食以长期食欲不振为主；疳证以形体消瘦、面黄发枯为特征。

【辨证论治】

分证论治

1. 乳食内积

  • 证候：不思乳食，嗳腐酸馊或呕吐食物、乳片，脘腹胀满，疼痛拒按，大便酸臭，哭闹不宁，夜眠不安，舌淡红苔白垢腻，脉弦滑。
  • 辨证要点：有乳食不节史，不思乳食，脘腹胀满，嗳吐酸腐，大便酸臭。
  • 治法：消乳化食，和中导滞。
  • 主方：乳积用消乳丸（《证治准绳》）；食积用保和丸（《丹溪心法》）。

2. 食积化热

  • 证候：不思乳食，口干，脘腹胀满，腹部灼热，手足心热，心烦易怒，夜寐不安，小便黄，大便臭秽或秘结，舌红苔黄腻，脉滑数。
  • 辨证要点：脘腹胀满，口干心烦，腹部皮肤灼热或手足心热，睡卧不宁。
  • 治法：清热导滞，消积和中。
  • 主方：枳实导滞丸（《内外伤辨惑论》）加减。

3. 脾虚夹积

  • 证候：面色萎黄，形体消瘦，神疲肢倦，不思乳食，食则饱胀，腹满喜按，大便稀溏酸腥，夹有乳片或不消化食物残渣，舌淡苔白腻，脉细滑。
  • 辨证要点：面黄神疲，腹满喜按，嗳吐酸腐，大便酸腥稀溏不化。
  • 治法：健脾助运，消食化滞。
  • 主方：健脾丸（《医方集解》）加减。

【其他疗法】

外治：玄明胡椒粉敷脐（乳食内积）；六神曲麦芽山楂等研末麻油调敷中脘、神阙（食积化热）。推拿分证治疗。针灸：体针（足三里、中脘、梁门等）；耳针（胃、大肠、神门、交感、脾）；刺四缝（乳食内积）。

十一、第九节 疳证

疳证是由喂养不当或多种疾病影响，导致脾胃受损，气液耗伤，不能濡养脏腑、经脉、筋骨、肌肤而形成的一种慢性消耗性疾病。临床以形体消瘦，面色无华，毛发干枯，精神萎靡或烦躁，饮食异常，大便不调为特征。5岁以下小儿多见。曾被列为儿科四大要证之一。

【病因病机】

病位主要在脾胃，可涉于五脏，病机为脾胃亏损，津液耗伤。

  1. 喂养不当：乳食无度（太过）→食积内停→积久成疳；乳食不足（不及）→营养失衡→气液亏损。
  2. 疾病影响：久病吐泻，反复外感，时行热病，肺痨诸虫→脾胃受损→津液耗伤→气血亏损。
  3. 禀赋不足：先天胎禀不足，早产多胎，孕期久病→元气虚惫→脾胃功能薄弱。

兼证：脾病及肝→肝阴不足→眼疳（视物不清，夜盲目翳）；脾病及心→心火上炎→口疳（口舌生疮）；脾阳虚失运→水湿泛滥→疳肿胀。

【临床诊断】

诊断要点：形体消瘦（体重比正常同龄儿童平均值低15%以上），面色不华，毛发稀疏枯黄，饮食异常，大便不调，或脘腹膨胀。皮下脂肪减少，皮肤干燥弹性差，肌肉松弛。

【辨证论治】

（一）辨证思路

  • 辨主证：疳气（初起，形体略瘦，食欲欠佳，精神如常，属虚证轻证）→疳积（明显消瘦，肚腹膨隆，烦躁多啼，属脾虚夹积，虚实夹杂）→干疳（极度消瘦，貌似老人，杳不思食，精神萎靡，属脾胃衰败，虚证重证）。
  • 辨兼证：脾病及心→口舌生疮（口疳）；脾病及肝→目生云翳、夜盲（眼疳）；脾阳虚衰→肌肤水肿（疳肿胀）。

（二）分证论治

1. 常证

（1）疳气

  • 证候：形体略瘦，或体重不增，面色萎黄少华，毛发稀疏，不思饮食，腹胀，精神欠佳，性急易怒，大便干稀不调，舌淡苔薄微腻，脉细有力。
  • 辨证要点：形体略瘦，食欲不振，性急易怒。
  • 治法：调和脾胃，益气助运。
  • 主方：资生健脾丸（缪仲淳方）加减。

（2）疳积

  • 证候：形体明显消瘦，面色萎黄少华或面白无华，肚腹膨胀，甚则青筋暴露，毛发稀疏结穗，精神烦躁，夜卧不宁，或见揉眉挖鼻，吮指磨牙，动作异常，食欲不振，或善食易饥，或嗜食异物，舌淡苔白腻，脉沉细而滑。
  • 辨证要点：形体明显消瘦，四肢枯细，肚腹膨胀，烦躁不宁。
  • 治法：消积理脾，和中清热。
  • 主方：肥儿丸（《医宗金鉴》）加减。

（3）干疳

  • 证候：形体极度消瘦，皮肤干瘪起皱，大肉已脱，皮包骨头，貌似老人，毛发干枯，面色㿠白，精神萎靡，懒言少动，啼哭无力，表情冷漠呆滞，腹凹如舟，杳不思食，大便稀溏或便秘，舌淡嫩苔花剥或无，脉沉细弱。
  • 辨证要点：形体极度消瘦，精神萎靡，杳不思食。
  • 治法：补脾益气，养血活血。
  • 主方：八珍汤（《正体类要》）加减。
2. 兼证

（1）眼疳

  • 证候：两目干涩，畏光羞明，眼角赤烂，甚则黑睛混浊，白翳遮睛或有夜盲眼痒，舌红苔薄白，脉细。
  • 治法：养血柔肝，滋阴明目。
  • 主方：石斛夜光丸（《原机启微》）加减；夜盲选羊肝丸（《审视瑶函》）加减。

（2）口疳

  • 证候：口舌生疮，甚或满口糜烂，秽臭难闻，面赤心烦，夜卧不宁，五心烦热，进食哭闹，小便短黄，舌尖红苔薄黄，脉细数。
  • 治法：清心泻火，滋阴生津。
  • 主方：泻心导赤散（《医宗金鉴》）加减。

（3）疳肿胀

  • 证候：足踝浮肿，眼睑浮肿，甚或颜面及全身浮肿，面色无华，神疲乏力，四肢欠温，小便短少，舌淡嫩苔薄白，脉沉迟无力。
  • 治法：健脾温阳，利水消肿。
  • 主方：防己黄芪汤（《金匮要略》）合五苓散（《伤寒论》）加减。

【其他疗法】

中成药：健儿素颗粒、乐儿康糖浆（疳气）；疳积散、化积口服液（疳积）；十全大补丸（干疳）；明目地黄丸（眼疳）。推拿分证治疗（捏脊可用于疳气、疳积，极度消瘦者慎用）。针灸：体针（合谷、曲池、中脘、气海、足三里、三阴交）；刺四缝（疳积）。

十二、第十节 缺铁性贫血

缺铁性贫血是体内铁缺乏导致血红蛋白合成减少的贫血症。小儿贫血中最常见类型，6个月～2岁发病率高。轻中度贫血一般预后良好，重度贫血影响生长发育，降低抗病能力。

【病因病机】

病位主要在脾胃，涉及心肝肾，病机为气血不足，血虚不荣。

  1. 禀赋不足：孕母体弱或孕期失养→精髓不足→气血内亏。
  2. 脾胃虚弱：喂养不当，偏食少食，感染诸虫，病后失调→脾胃受损→化生气血不足。
  3. 心脾两虚：血虚日久→脾胃虚弱→气血化生乏源→心血不足→心脾两虚。
  4. 肝肾阴虚：血虚日久→久病伤阴→肝肾同源→精血亏虚。
  5. 脾肾阳虚：脾肾阳虚→精血无以化生。
  6. 精血丢失：虫积吮吸血液，外伤失血，慢性失血。

【临床诊断】

诊断要点：

  • 病史：先天储铁不足，铁供给不足，铁吸收障碍，铁丢失过多。
  • 临床表现：轻度常无自觉症状；中重度见面色苍白或苍黄，神疲乏力，烦躁不安或萎靡，注意力不集中，食欲减退，年长儿可诉头晕、心悸等。
  • 体征：皮肤黏膜苍白（以唇、口腔黏膜、甲床、手掌最明显），部分有肝脾淋巴结肿大。
  • 辅助检查：血红蛋白（3月～6岁<110g/L，6岁以上<120g/L）；MCV<80fL，MCH<27pg，MCHC<310g/L；血清铁蛋白<15μg/L。
  • 分度：轻度（Hb 90～110g/L），中度（Hb 60～90g/L），重度（Hb 30～60g/L），极重度（Hb<30g/L）。
  • 铁剂治疗有效（4周后Hb上升20g/L以上）。

鉴别诊断：与婴儿生理性贫血、营养性巨幼细胞性贫血、地中海贫血、铁粒幼红细胞贫血鉴别（见表5-9）。

【辨证论治】

分证论治

1. 脾胃虚弱

  • 证候：面色萎黄或苍黄，唇甲色淡，形体消瘦，神疲乏力，食欲不振，肌肉松弛，大便不调，舌淡苔白，脉细无力。
  • 辨证要点：面色苍黄，唇甲色淡，神疲乏力，肌肉松弛，食欲不振。
  • 治法：健运脾胃，益气养血。
  • 主方：六君子汤（《太平惠民和剂局方》）合当归补血汤（《内外伤辨惑论》）加减。

2. 心脾两虚

  • 证候：面色萎黄或苍白，唇甲色淡，发黄稀疏，心悸怔忡，头晕目眩，夜寐不安，气短懒言，注意力涣散，体倦乏力，食欲不振，舌淡红脉细弱。
  • 辨证要点：面色萎黄或苍白，心悸，夜寐不安，气短懒言，注意力涣散。
  • 治法：补脾养心，益气生血。
  • 主方：归脾汤（《正体类要》）加减。

3. 肝肾阴虚

  • 证候：面色苍白，毛发枯黄，爪甲色白易脆，耳鸣目涩，盗汗，面色颧红，腰膝酸软，发育迟缓，口舌干燥，甚或皮肤瘀斑，吐血衄血，烦躁失眠，四肢震颤，舌红少津苔少或光剥，脉细数。
  • 辨证要点：面色苍白，爪甲色白质脆，耳鸣目涩，腰膝酸软，烦躁盗汗，发育迟缓，舌红少津。
  • 治法：滋养肝肾，调补精血。
  • 主方：左归丸（《景岳全书》）加减。

4. 脾肾阳虚

  • 证候：面色㿠白，唇甲苍白，发黄稀少，精神萎靡，畏寒肢冷，纳呆便溏，或完谷不化，消瘦或浮肿，发育迟缓，舌淡苔白舌体胖嫩，脉沉细无力。
  • 辨证要点：精神萎靡，面色㿠白，畏寒肢冷，发育迟缓，纳呆便溏。
  • 治法：温补脾肾，填精养血。
  • 主方：右归丸（《景岳全书》）加减。

【其他疗法】

中成药：健脾生血颗粒（脾胃虚弱/心脾两虚）；小儿生血糖浆；归芪口服液；复方阿胶浆。推拿（补脾经、推三关、补心经、揉足三里、捏脊）。针灸（膈俞、足三里、隐白、三阴交为主穴）。

西医：合理喂养，增加富含铁质、维生素C和蛋白质食物；祛除病因；口服铁剂（二价铁盐，4～6mg/kg·d，餐间服用，同时口服维生素C促进吸收，Hb正常后再服2个月）；重症贫血输血治疗（Hb<30g/L用等量换血，30～60g/L输浓缩红细胞4～6mL/kg）。
