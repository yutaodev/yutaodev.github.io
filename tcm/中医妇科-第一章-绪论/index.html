二、第一节 学科基础定位

1. 学科定义

中医妇科学是以中医理论为指导，研究女性特有生理、病理规律，防治女性特有疾病的一门临床学科，是中医学重要分支。

2. 研究范围

五大板块：月经病、带下病、妊娠病、产后病、妇科杂病； 对应女性特有生理：月经、带下、妊娠、分娩、产褥。

3. 学科核心价值

自古重视生育繁衍，历代逐步分化出独立妇科/产科，形成完整理法方药体系，至今指导妇科临床，中西医结合拓展诊疗优势。

三、第二节 妇产科学发展简史

（一）夏、商、西周时代——萌芽阶段

  1. 史料记载
    • 甲骨文出现疾育，是最早妇产科疾病文字记录；
    • 《史记》记载上古难产案例（修己背坼生禹、剖产生子）；
    • 《诗经》《山海经》收录大量妇产科专用药，含种子、避孕类药物。
  2. 核心理论雏形：胎教 《列女传》记载文王之母太任胎教思想：孕期慎视听、言行，重视情志对胎儿发育影响，为后世孕期调护理论源头。

（二）春秋战国时代——理论奠基期

  1. 专科医者：扁鹊首创带下医，为最早专职妇科医师。
  2. 优生认知：《左传》提出男女同姓，其生不蕃，明确近亲婚配危害。
  3. 胚胎发育记载：《文子·九守篇》完整记述十月胚胎发育过程。
  4. 《黄帝内经》（核心奠基）
    • 确立女性解剖、月经生理、妊娠诊断基础理论；
    • 最早记载妇科病症：血枯、闭经、带下、不孕、肠覃、石瘕；
    • 创制妇科第一方：四乌贼骨一藘茹丸，主治血枯经闭；
    • 全书构建的脏腑、经络、气血理论为后世妇科辨证总纲领。

（三）秦汉时代——病案、专著、产科手术突破

  1. 秦代：淳于意（太仓公）首创诊籍，留存我国最早2则妇产科病案：宫寒闭经、难产不乳。
  2. 汉代医事与技术突破
    • 设立女医（乳医），专职宫廷孕产疾病；
    • 首见药物堕胎、联体双胎、死胎取出手术记载；
    • 现存最早产科专著：《胎产书》，记载逐月孕期养生。
  3. 两大医学经典贡献
    1. 张仲景《金匮要略·妇人三篇》 系统论述经、带、妊娠、产后诸病（恶阻、妊娠腹痛、产后发热、热入血室等）；首创妇科阴道冲洗、纳药外治法，所载方剂沿用至今。
    2. 华佗：成功实施宫腔死胎摘除手术，古代妇产科外科代表。

（四）魏晋南北朝及隋代——脉学、养胎、节育理论发展

  1. 晋·王叔和《脉经》 妇科脉学里程碑：提出居经、避年特殊月经生理；区分胎脉、产时离经脉；系统记录妇科病脉证。
  2. 南齐·褚澄《褚氏遗书》 倡导晚婚节育：男三十而娶、女二十而嫁；指出多产、房事过度耗伤女性气血，保护妇女健康。
  3. 北齐·徐之才《逐月养胎法》 细化十月胚胎发育与分月孕期调养，成为后世孕期保健标准理论。
  4. 史料记载针刺引产成功案例，拓展产科外治手段。

（五）唐代——产科专著成型

  1. 医著背景：出现大量妇产科方书（《子母秘录》），但多散佚。
  2. 现存第一部体系完整产科专著：昝殷《经效产宝》（852-856年）
    • 全书3卷，分41门，载260余方；
    • 覆盖妊娠、临产、产后全部病证；
    • 首次提出产后三冲（冲心、冲胃、冲肺），明确产后危重症，对后世产科影响深远。

（六）宋代——产科独立分科，妇科体系大成

  1. 医事制度里程碑：宋代太医局九科，产科正式独立专科，定额招生，是妇产科专业化标志。
  2. 重点专著与贡献
    1. 杨子建《十产论》：详述正产、横产、倒产等十种产式，记载转胎助产手法，古代难产诊疗权威著作。
    2. 朱端章《卫生家宝产科备要》：汇总宋以前产科文献，完整记载产后三冲、新生儿养护。
    3. 齐仲甫《女科百问》：以问答体例梳理经带胎产杂病，首次广泛使用“胞宫”病位术语。
    4. 陈自明《妇人大全良方》（宋代妇科最高成就，1237年）
      • 全书24卷，分调经、众疾、求嗣、胎教、妊娠、坐月、产难、产后8大门；
      • 核心病机：冲任为十二经脉之海，妇人诸病根源在于冲任损伤、病在胞宫；治疗重视肝脾气血生化；
      • 整合宋以前30余种妇科专著，方药、医案齐备，风行后世300余年。
  3. 同期大型方书《太平圣惠方》《圣济总录》均设妇科专篇。

（七）金元时期——流派开拓妇科论治思路

金元四大家学术思想广泛应用妇科，丰富辨证用药：

  • 刘完素“六气皆从火化”，寒凉治法常用于妇科热证、血热月经病； 元代医学分为13科，产科单独设科，延续宋代分科制度。

（八）明代——妇人科独立，肾命门学说指导妇科

  1. 医事制度：明代医学13科，妇人科独立设置。
  2. 核心学术发展：命门、肾阴肾阳学说全面融入妇科，确立肾为月经、胎元根本的理论。
  3. 代表医家与著作
    1. 薛己《校注妇人良方》《女科撮要》：以命门阴阳立论，温补脾肾治疗妇科虚证。
    2. 万全《广嗣纪要》：提出五不女（螺、纹、鼓、角、脉），记载女性先天生殖缺陷；另有《妇人秘科》总结妇科常见病论治。
    3. 王肯堂《证治准绳·女科》：集明前妇科文献大成，病证分类详尽。
    4. 武之望《济阴纲目》：纲目清晰，妇科临床工具书。
    5. 赵献可《邯郸遗稿》：核心观点：肾中水火为冲任根本、胎元所系；滋水、温火分治肾虚月经、胎动不安，拓展补肾调经安胎治法。
    6. 张介宾《景岳全书·妇人规》：重肝肾、精血，温补思路完善妇科虚损证治。

（九）清代与民国——传世经典普及

清代统称妇科为妇人科/女科，专科持续独立；民国战乱，妇科专著产出减少。

  1. 明末清初·傅山《傅青主女科》（1827年初刊） 辨证核心立足肝、脾、肾三脏，方药精简效佳，立论独到，后世妇科必读经典。
  2. 亟斋居士《达生篇》：通俗产科读物，普及胎前、临产、产后日常调护，民间流传极广。
  3. 官方医籍《医宗金鉴·妇科心法要诀》：政府编撰，歌诀体例，条理规范，历代医学生通用教材。
  4. 王清任、张锡纯：创制固冲汤、安冲汤、寿胎丸等名方，沿用至今；张山雷《沈氏女科辑要笺正》完善肝肾论治体系，近代妇科教学核心用书。

（十）中华人民共和国成立后——标准化、现代化发展

  1. 教材体系：统一规划《中医妇科学》本科教材，配套百科全书、教学参考丛书，统一教学逻辑。
  2. 人才培养：1979年开设妇科硕士教育，1982年设立博士点，培养高层次专科人才。
  3. 国家级重点学科：黑龙江中医药大学、广州中医药大学中医妇科学为国家重点学科。
  4. 中西医结合标志性科研成果
    • 肾藏象研究：无排卵功血、妊娠中毒症中医辨证机制；
    • 山西医学院：中西医结合保守治疗宫外孕；
    • 江西妇幼保健院：中药外用治疗早期宫颈癌；
  5. 产业化：研发妇科中成药，标准化应用于临床。

四、本章复习思考题答题要点

  1. 简述《黄帝内经》对中医妇科学的奠基作用 ① 确立女性解剖、月经、妊娠基础生理理论；② 记载血枯、闭经、不孕、肠覃、石瘕等最早妇科疾病；③ 创制妇科首方四乌贼骨一藘茹丸；④ 建立脏腑、经络、气血辨证总框架，成为后世妇科理论根源。
  2. 简述宋代妇产科发展标志性成就 ① 医事制度：太医局九科设独立产科，为历史首次专科化；② 代表著作《十产论》记载转胎助产，《妇人大全良方》系统整合妇科8大门类，提出冲任损伤为妇人病核心病机；③ “胞宫”病位术语普及，完整梳理经带胎产全套理法方药。
  3. 何为产后三冲，首见于哪本著作？ 产后三冲：冲心、冲胃、冲肺；首见于唐代昝殷《经效产宝》，为产后危重并发症。
  4. 简述《金匮要略·妇人三篇》学术贡献 系统划分妊娠、产后、杂病三类妇科疾病；记载热入血室、恶阻、产后发热等经典病证；开创妇科阴道冲洗、纳药外治；所载方剂千年沿用，建立妇科辨证论治完整范式。
  5. 五不女出自哪本书，具体指什么？ 万全《广嗣纪要》；五不女：螺、纹、鼓、角、脉，指代五种先天生殖发育缺陷，难以受孕。
  6. 傅青主女科核心辨证思路是什么？ 以肝、脾、肾三脏为辨证核心，分清气血、阴阳虚实，用药平和精准，调经、种子、安胎、治带均自成体系，方药简廉效捷。
  7. 新中国成立后中医妇科主要发展成果有哪些？ ① 统一标准化本科教材，建立完整教学体系；② 设立硕博高层次人才培养；③ 评选国家级重点学科；④ 多项标志性中西医结合妇科科研（宫外孕、功血、宫颈病变等）；⑤ 妇科中成药标准化产业化，拓展临床应用。
  8. 简述扁鹊、淳于意在妇科史上的地位 扁鹊：我国第一位专职妇科医师，称“带下医”，开创专科诊疗先河；淳于意：创立诊籍，留存最早妇产科病案，开启妇科病案记录传统。
  9. 徐之才《逐月养胎法》核心内容 系统描述十月胚胎生长规律，按月划分孕期调养方法，是古代孕期保健、安胎理论的核心文献，影响后世所有产科养生体系。
  10. 褚澄《褚氏遗书》对妇女保健的主张 倡导晚婚：男三十、女二十婚嫁，待阴阳气血充盛再婚配生育；提出多产、纵欲耗伤阴血，主张节育，重视女性气血养护。
