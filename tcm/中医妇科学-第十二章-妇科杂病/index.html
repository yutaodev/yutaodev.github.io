二、总论

凡不属经、带、胎、产和前阴疾病范畴，而又与女性解剖、生理特点有密切关系的疾病，称为“妇科杂病”。常见有不孕症、妇人腹痛、癥瘕、阴挺。

病因：起居不慎感受外邪；脏腑气血阴阳失调；禀赋不足或情志、心理因素、环境刺激。

治疗要点：不孕症宜温养肾气、调理冲任气血为主；癥瘕宜理气散结、破血消瘀，必察正气盛衰酌用攻补；阴挺宜补气升提为主，夹湿热者又宜清热渗湿；妇人腹痛宜根据病情急慢性分别施治。

三、第一节 不孕症

定义：女子未避孕，性生活正常，与配偶同居1年而未孕者。原发性不孕称“全不产”；继发性不孕称“断绪”。

【病因病机】

主要病机为肾气不足，冲任气血失调。

  1. 肾虚：先天不足、房劳多产、久病大病，肾气亏虚，冲任虚衰；肾阳不足胞宫失煦；肾阴亏虚天癸乏源。
  2. 肝气郁结：情志不畅，肝郁气滞，冲任失和。
  3. 痰湿内阻：脾虚运化失司，湿聚成痰，冲任壅滞。
  4. 瘀滞胞宫：经行产后摄生不慎，邪入胞宫致瘀，瘀滞冲任胞宫。

【诊断】

  1. 病史：年龄、婚史、同居时间、配偶健康、性生活、月经史、产育史、既往史及家族史（结核、甲状腺疾病、糖尿病、盆腹腔手术史）。
  2. 症状：未避孕、性生活正常、同居1年或曾孕育后未避孕1年而未孕。
  3. 检查：
    • 体格检查：身高、体重、第二性征、体毛分布、溢乳。
    • 妇科检查：内外生殖器发育、畸形、炎症、包块。
    • 辅助检查：卵巢功能检查（BBT、超声监测排卵、宫颈黏液结晶、内膜活检、激素测定）；输卵管通畅试验；免疫因素检查；宫腔镜检查；腹腔镜检查。

【辨证论治】

（一）辨证要点

根据月经、带下、全身症状及舌脉综合分析，审脏腑、冲任、胞宫之病位，辨气血、寒热、虚实。辨病与辨证相结合。

（二）治疗原则

温养肾气、调理气血为主。调畅情志，择“的候”而合阴阳。

（三）分型论治

1. 肾虚证

（1）肾气虚证

主要证候：婚久不孕，月经不调或停闭，量多或少，色淡暗质稀；腰膝酸软，头晕耳鸣，精神疲倦，小便清长；舌淡苔薄白，脉沉细两尺尤甚。

治法：补益肾气，调补冲任。

方药：毓麟珠（四物汤+四君子汤+菟丝子、杜仲、鹿角霜、川椒）。

（2）肾阳虚证

主要证候：婚久不孕，初潮延迟，月经后期量少色淡质稀甚至停闭，带下量多清稀如水；腰膝酸冷，性欲淡漠，面色晦暗，大便溏薄，小便清长；舌淡苔白，脉沉迟。

治法：温肾助阳，调补冲任。

方药：温胞饮（巴戟天、补骨脂、菟丝子、肉桂、附子、杜仲、白术、山药、芡实、人参）。

（3）肾阴虚证

主要证候：婚久不孕，月经先期量少色红质稠甚或闭经，带下量少阴中干涩；腰膝酸软，头晕耳鸣，形体消瘦，五心烦热，失眠多梦；舌淡或舌红少苔，脉细或细数。

治法：滋肾养血，调补冲任。

方药：养精种玉汤（当归、白芍、熟地黄、山茱萸）。

2. 肝气郁结证

主要证候：婚久不孕，月经周期先后不定，量或多或少色暗有血块，经行腹痛或经前胸胁乳房胀痛；情志抑郁或烦躁易怒；舌淡红苔薄白，脉弦。

治法：疏肝解郁，理血调经。

方药：开郁种玉汤（当归、白芍、牡丹皮、香附、白术、茯苓、天花粉）。

3. 痰湿内阻证

主要证候：婚久不孕，月经后期甚或闭经，带下量多色白质黏；形体肥胖，胸闷呕恶，心悸头晕；舌淡胖苔白腻，脉滑。

治法：燥湿化痰，理气调经。

方药：苍附导痰丸（方见月经后期）。

4. 瘀滞胞宫证

主要证候：婚久不孕，月经后期量或多或少色紫黑有血块可伴痛经；平素小腹或少腹疼痛或肛门坠胀；舌紫暗边有瘀点，脉弦涩。

治法：活血化瘀，止痛调经。

方药：少腹逐瘀汤（方见痛经）。

【临证要点】

不孕病因复杂，需详问病史，认真查体，明辨病因，分析病位。重视男方因素，提倡夫妇同诊。“求子之道，莫如调经”，种子必先调经。重在补肾、疏肝、理血，兼有痰瘀则祛瘀化痰。注重病证结合治疗与中西医结合治疗，辅以心理治疗。

四、第二节 妇人腹痛

定义：妇女不在行经、妊娠及产褥期间发生小腹或少腹疼痛，甚则痛连腰骶。

【病因病机】

冲任虚衰，胞脉失养，“不荣则痛”；冲任阻滞，胞脉失畅，“不通则痛”。分肾阳虚衰、血虚失荣、感染邪毒、湿热瘀结、气滞血瘀、寒湿凝滞。

【诊断】

  1. 病史：育龄期妇女，曾有生产、流产、宫腔内手术史，或放置宫内节育器。
  2. 症状：下腹部疼痛，或伴发热，经前或经期加重；阴道肛门坠痛；劳累、久站或性交后加重；带下异常。
  3. 检查：妇科检查宫颈肥大、子宫体压痛、活动受限、附件区压痛或包块；实验室检查宫颈黏液脓性分泌物、白细胞增多、ESR/CRP升高。

【鉴别诊断】

需与异位妊娠、肠痈（急性阑尾炎）、卵巢囊肿蒂扭转鉴别。

【辨证论治】

（一）辨证要点

辨疼痛部位、性质、程度及发作时间，结合全身症状、月经及带下改变，审寒热虚实。慢性腹痛多见虚中夹实。

（二）治疗原则

通调冲任气血为主。发病急重者必要时中西医结合治疗。

（三）分型论治

1. 肾阳虚衰证

主要证候：小腹冷痛下坠，喜温喜按，腰膝酸软，头晕耳鸣，畏寒肢冷，小便频数夜尿多，大便不实；舌淡苔白滑，脉沉弱。

治法：温肾助阳，暖宫止痛。

方药：温胞饮（方见不孕症）。

2. 血虚失荣证

主要证候：小腹隐痛喜按，头晕眼花，心悸少寐，大便燥结，面色萎黄；舌淡苔少，脉细。

治法：补血养营，和中止痛。

方药：当归建中汤（当归、桂枝、白芍、甘草、生姜、大枣、饴糖）。

3. 感染邪毒证

主要证候：小腹疼痛或全腹疼痛拒按，寒热往来或持续高热，带下量多臭秽如脓或夹血，心烦口渴，甚则神昏谵语，大便秘结，小便短赤；舌红苔黄而干，脉弦数。

治法：清热解毒，凉血化瘀。

方药：解毒活血汤（方见产后发热）加金银花、黄芩。

危重变证：

  • 热入阳明（全腹满痛、高热、大便燥结）：桃核承气汤加减。
  • 热入营血（高热汗出、斑疹隐隐）：清营汤加减。
  • 热陷心包（神昏谵语、四肢厥冷）：清营汤送服安宫牛黄丸或紫雪丹。
4. 湿热瘀结证

主要证候：小腹疼痛拒按有灼热感或有积块，伴腰骶胀痛，低热起伏，带下量多黄稠有臭味，小便短黄；舌红苔黄腻，脉弦滑数。

治法：清热除湿，化瘀止痛。

方药：清热调血汤（方见痛经）加败酱草、薏苡仁、土茯苓。

5. 气滞血瘀证

主要证候：小腹或少腹胀痛拒按，胸胁乳房胀痛，脘腹胀满，食欲欠佳，烦躁易怒，时欲太息；舌紫暗或有瘀点，脉弦涩。

治法：行气活血，化瘀止痛。

方药：牡丹散（牡丹皮、桂心、当归、延胡索、莪术、牛膝、赤芍、三棱）。

6. 寒湿凝滞证

主要证候：小腹冷痛痛处不移，得温痛减，带下量多色白质稀，形寒肢冷，面色青白；舌淡苔白腻，脉沉紧。

治法：散寒除湿，化瘀止痛。

方药：少腹逐瘀汤（方见痛经）加苍术、茯苓。

【其他疗法】

中药保留灌肠、直肠用药（康妇消炎栓）、中成药（妇科千金片、妇乐颗粒、止痛化癥胶囊、散结镇痛胶囊）。

五、第三节 癥瘕

定义：妇女小腹内的结块，伴有或胀、或痛、或满，并常致月经或带下异常，甚至影响生育。癥者，坚硬成块，固定不移，痛有定处，病属血分；瘕者，积块不坚，推之可移，痛无定处，病属气分。

【病因病机】

正气不足，风寒湿热之邪内侵或七情、房事、饮食所伤，脏腑功能失调，致气滞、瘀血、痰湿、湿热等病理产物聚结于冲任、胞宫、胞脉，久而聚成癥瘕。分气滞血瘀、寒凝血瘀、痰湿瘀结、气虚血瘀、肾虚血瘀、湿热瘀阻。

【诊断】

  1. 病史：情志抑郁，经行产后感受外邪，月经不调，带下异常等。
  2. 症状：异常子宫出血、异常带下、小腹胀满或疼痛。
  3. 检查：妇科检查盆腔内可触及异常包块；影像学检查（超声、CT、MRI）；腹腔镜、宫腔镜检查及病理活检。

【鉴别诊断】

需与妊娠子宫、卵巢囊肿、子宫肌瘤、盆腔炎性疾病、陈旧性宫外孕等鉴别。

【辨证论治】

（一）辨证要点

  • 辨善恶：良性（生长缓慢、质软、边界清、活动好）；恶性（生长快、质硬、边界不清、伴消瘦腹水）。
  • 辨虚实：实邪属瘀、痰、寒、湿、热；虚者属气虚、肾虚。

（二）治疗原则

活血化瘀，软坚散结。根据寒热虚实属性，结合体质及病程酌用攻补。

（三）分型论治

1. 气滞血瘀证

主要证候：下腹包块质硬，下腹或胀或痛，经期延长或经量多色暗夹血块，经行腹痛；精神抑郁，善太息，胸胁胀闷，乳房胀痛，面色晦暗；舌暗边有瘀点，脉弦涩。

治法：行气活血，化瘀消癥。

方药：香棱丸（木香、丁香、三棱、枳壳、青皮、川楝子、小茴香、莪术）。

2. 寒凝血瘀证

主要证候：下腹包块质硬，小腹冷痛喜温，月经后期量少色暗淡有血块，经行腹痛；形寒肢冷，面色晦暗；舌淡暗边有瘀点，脉弦紧。

治法：温经散寒，祛瘀消癥。

方药：少腹逐瘀汤（方见痛经）。

3. 痰湿瘀结证

主要证候：下腹包块按之不坚，小腹或胀或满，月经后期或闭经，经质黏稠夹血块；形体肥胖，胸脘痞闷，肢体困倦，带下量多色白质黏；舌暗淡边有瘀点苔白腻，脉弦滑或沉滑。

治法：化痰除湿，活血消癥。

方药：苍附导痰丸（方见月经后期）合桂枝茯苓丸（方见胎动不安）。

4. 气虚血瘀证

主要证候：下腹部结块，下腹空坠，月经量多或经期延长色淡红有血块，经行或经后下腹痛；面色无华，气短懒言，倦怠嗜卧，纳少便溏；舌暗淡边有瘀点，脉细涩。

治法：补气活血，化瘀消癥。

方药：理冲汤（生黄芪、党参、白术、生山药、天花粉、知母、三棱、莪术、生鸡内金）。

5. 肾虚血瘀证

主要证候：下腹部积块，下腹或胀或痛，月经后期量或多或少色紫暗有血块，婚久不孕，腰膝酸软，小便清长夜尿多；舌淡暗边有瘀点苔白润，脉沉涩。

治法：补肾活血，消瘀散结。

方药：肾气丸（方见经行浮肿）合桂枝茯苓丸（方见胎动不安）。

6. 湿热瘀阻证

主要证候：下腹积块，小腹或胀或痛，带下量多色黄，月经量多经期延长色暗有血块质黏稠，经行腹痛；身热口渴，心烦不宁，大便秘结，小便黄赤；舌暗红边有瘀点苔黄腻，脉弦滑数。

治法：清利湿热，化瘀消癥。

方药：大黄牡丹汤（大黄、牡丹皮、桃仁、冬瓜仁、芒硝）。

【其他疗法】

桂枝茯苓胶囊、宫瘤消胶囊、大黄䗪虫丸、丹鳖胶囊等中成药。

【临证要点】

临证务必排除恶性肿瘤及良性肿瘤恶性变。癥瘕病机复杂，各种有形病邪易相互胶结，尤以痰瘀互结为突出特点，正邪相争、虚实互见。临证除辨证外，还应结合辨西医之“病”，如子宫肌瘤用扶正软坚散瘀消瘤法；子宫内膜异位症多用补肾化瘀消瘤法；卵巢型子宫内膜异位囊肿、多囊卵巢综合征可痰瘀同治。

六、第四节 阴挺

定义：妇女子宫下脱，甚则脱出阴户之外，或阴道壁膨出。又称“阴脱”“阴菌”“阴痔”“产肠不收”等。

【病因病机】

主要病机为气虚下陷与肾虚不固，致胞络受损，带脉提摄无力，子宫脱出。

  1. 气虚：素体虚弱，中气不足；分娩损伤，冲任不固；产后过劳，耗气伤中；长期咳嗽、便秘，脾气虚弱，中气下陷。
  2. 肾虚：先天不足，年老体虚，房劳多产，胞络损伤，系胞无力。
  3. 兼湿热：子宫脱出阴户之外，调护不慎，邪气入侵，湿热下注，可致溃烂。

【诊断】

  1. 病史：分娩损伤史，产后过早操劳，产育过多，慢性咳嗽、便秘史，年老体弱。
  2. 症状：有物自阴道下坠甚至脱出阴道口外，卧床休息可变小或消失，劳累后加重；腰骶酸痛，小腹下坠，排尿困难、尿频或失禁，大便秘结。
  3. 妇科检查（分度）：
    • Ⅰ度：轻型——宫颈外口距处女膜缘＜4cm；重型——宫颈已达处女膜缘。
    • Ⅱ度：轻型——宫颈脱出阴道口，宫体仍在阴道内；重型——部分宫体脱出。
    • Ⅲ度：宫颈与宫体全部脱出。

【鉴别诊断】

需与子宫黏膜下肌瘤（带蒂脱出型）、阴道壁肿物鉴别。

【辨证论治】

（一）辨证要点

病因为气虚及肾虚，可兼湿热之标证。

（二）治疗原则

“虚者补之，陷者举之，脱者固之”——益气升提、补肾固脱为主，兼湿热者佐以清热利湿。

（三）分型论治

1. 气虚证

主要证候：子宫下移或脱出阴道口外，劳则加剧；小腹下坠，少气懒言，四肢乏力，面色少华，小便频数，或带下量多色白质稀；舌淡苔薄，脉虚细。

治法：补中益气，升阳举陷。

方药：补中益气汤（方见月经先期）加金樱子、杜仲、续断。

加减：兼湿热（带下色黄质黏臭秽）加黄柏、败酱草、薏苡仁；小便频数或失禁加覆盆子、桑螵蛸。

2. 肾虚证

主要证候：子宫下移或脱出阴道口外，劳则加剧；小腹下坠，腰膝酸软，头晕耳鸣，小便频数入夜尤甚；舌淡苔薄，脉沉弱。

治法：补肾固脱，益气升提。

方药：大补元煎（方见月经后期）加黄芪。

加减：腰膝酸冷（命门火衰）加补骨脂、肉桂；带下量多色白质稀加海螵蛸、芡实；红肿溃烂、黄水淋漓（湿热）先用龙胆泻肝汤或易黄汤，湿热清除后仍补气扶正固本。

【其他疗法】

  1. 盆底肌肉锻炼（Kegel锻炼）：收缩肛门运动，每次10～15分钟，每日2～3次。
  2. 子宫托：适用于Ⅰ、Ⅱ度脱垂。
  3. 手术治疗：脱垂超出处女膜且有症状者，根据年龄、生育要求个体化治疗。

【临证要点】

重点详细询问病史，妇科检查，完善相关检查，与相关疾病鉴别。辨证以阴挺主证要素为主，结合全身症状、舌脉、病史综合分析。保守治疗无效、Ⅲ度脱垂伴症状者应手术治疗。
